# dessin-android

構図・下絵用の3Dデッサン人形ツール(Android / Kotlin)。

## 現状(2026-11-14)
- 最新は v1.2.0。実機(Pixel 10a)に入れてあり、利用者がしばらく使ってから次の作業を決める
- v1.1.0・v1.2.0 で入れた機能は、利用者による実機での操作の確認がまだ(見てほしい点は `docs/issues/README.md`)
- 変更の履歴は `CHANGELOG.md`、作業の経緯と次の作業は `docs/issues/README.md`

## できること
### 人形を組む
- 胸を置き、肩・首・脇腹・骨盤…と親から子へ部位を一つずつ置く(手はグー・パー、足はつま先まで)。親を動かすと子孫も追従する
- 各部位は、親からの可動域(緑の範囲)の中で玉をドラッグするか、緑の範囲を2回タップして向きを決める。回転オーブでひねり・傾けもできる
- 部位を置いたときと「向きを戻す」は自然な姿勢(首と脇腹が少し前傾、太ももは少しハの字)になる
- 脇腹を選んでいるとき、根を胸か骨盤に切り替えられる(骨盤なら、脚を残して上半身を曲げられる)

### 体型
- 頭の大きさ・肩幅・骨盤の横幅・首の長さと付け根・腕と脚の長さ・身長・ひざの転がり・乳房の大きさ・性別を、部位を選んだときのスライダーで変える
- 体型はポーズと別に名前を付けて保存・読み込みできる
- 保存した体型の1つを既定にできる。起動したとき・人形を足したとき・「既定の体型に戻す」でその体型になる

### 複数の人形
- 10体まで置ける。右上の「人形」で人形のモードにし、人形を選ぶ・足す・消す(3D でタップしても選べる)。体型は人形ごと

### 見る
- 指で視点を回し、ピンチで拡大縮小する。マウスホイールでも拡大縮小できる
- 右上の「カメラ」で、部位を動かさずに視点だけを操作するモード(2本指で平行移動)
- 正面・横・背面・上と全体を表示に切り替えられる
- ガイド(可動域)・正中線・関節の玉・格子・体に落ちる影の表示を切り替えられる

### 保存
- 場面(全員の位置・ポーズ・体型)を名前を付けて複数保存し、一覧から読み込み・削除できる。v1.0 で保存した1体のポーズも読める
- ほかのアプリに切り替えている間にアプリが終了されても、作業中の状態は残る。アプリを自分で閉じる(履歴から消す)と初めの状態に戻るので、残したい場面は保存する
- 出力は端末のスクリーンショット
