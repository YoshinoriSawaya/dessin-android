# dessin-android

構図・下絵用の3Dデッサン人形ツール(Android / Kotlin)。

## 現状
- v1 の機能は実装済み(Web版の機能すべてと、ポーズの保存)。エミュレータで動作を確認し、実機での確認待ち
- Web版(`docs/web-reference.html`、three.js の単一HTML)が参照実装。ロジック・カメラ・形・ピッキングは Web版と照合するテストで一致を確かめている
- v1 の範囲と残りの作業は `docs/issues/README.md` に記載

## 概要
- 肋骨ブロックを置き、肩・首・骨盤…と親から子へ一つずつ配置する
- 各部位は、親からの可動域(緑の領域)内で、玉のドラッグまたは緑領域のダブルタップで位置決めする
- 3Dで回転でき、左右は別々に配置する。親を置き直すと子孫も追従する
- 視点は指で回転・ピンチで拡大縮小でき、正面・横・背面・上と全体を表示に切り替えられる
- ガイド(可動域)・正中線・関節の玉・格子の表示を切り替えられる
- ポーズは名前を付けて複数保存でき、一覧から読み込み・削除できる
- 出力はスクリーンショット
