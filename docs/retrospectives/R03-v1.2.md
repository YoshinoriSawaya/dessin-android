# R03 v1.2.0(2026-11-14)

カメラだけを操作するモード(E12)と、複数の人形(E13)を入れた。v1.1.0 と同じ日に出した。実機には入れたが、利用者による操作の確認はまだ。

## 想定外だったこと
- 複数の人形は、骨格・選択・保存がすべて1体を前提にしていたので大きな変更になると見ていたが、操作中の人形を今までどおり `skeleton` に持ち、ほかを別に持つ形にしたことで、今までの操作のコードと既存のテストをほとんど変えずに済んだ
- 保存を場面に変えると今までのポーズのファイルが読めなくなるところだったが、保存の一覧の仕組みに「ほかの種類も読む」を足して両方を並べられた
- 自分で書いたテストの準備が誤っていた(身長のスライダーは胸を選んでいるときにしか効かないのに、首を選んだまま動かしていた)。失敗の理由を実装ではなくテストの側に見つけた
- 実機へのインストールが、実機の画面の確認待ちで止まることがあった。裏で動かすようにした
- エミュレータでは2本指の操作を試せない(adb の制限)。平行移動はテストでしか確かめていない

## 次に活かすこと
- データの持ち方を変えるときは、今のコードの多くをそのまま使える形(今の型を中心に残し、増える分を横に足す)を先に探す
- テストが失敗したら、実装を直す前にテストの準備が正しいかを確かめる(テストを実装に合わせて書き換えるのではなく、準備の誤りを直す)
- 実機での操作の確認がたまっている(v1.1.0・v1.2.0)。次はまず利用者に触ってもらい、指摘を直してから新しいことに入る
