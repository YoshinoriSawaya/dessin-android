# R04 v1.3.0(2026-11-14)

利用者が使ってみる期間の途中で、ひざの転がりのずれで右側の部位がずれる不具合の修正と、既定の体型(E07-04)を入れた。既定の体型は実機で利用者が確認した。

## 想定外だったこと
- 使ってみる期間の要望は staging に下書きとして置くつもりだったが、利用者が確認したいことにすぐ答えたので、その場で実装まで進めた
- 体型の一覧にボタンを1つ足しただけで、名前が切れ、「既定」の印がボタンに重なった。エミュレータのスクリーンショットで初めて気づいた
- Windows の Python でファイルを書き換えると改行が CRLF になり、Git Bash から渡した日本語の引数は文字化けした

## 次に活かすこと
- ダイアログや行にボタンを足したら、エミュレータで名前が長いときの見た目を必ず見る
- ソースの書き換えは Edit を使う。スクリプトで書くときは改行を指定し(`newline=''`)、日本語は引数で渡さない
- staging の下書きでも、利用者が確認したいことに答えれば、そのまま実装に進める
