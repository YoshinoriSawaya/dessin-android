# R08 v1.7.0(2026-11-15)

骨盤が根のとき、脇腹は骨盤との関節、胸はみぞおちで動かすようにした(E16-01)。根の切り替えを操作パネルの行から 3D の右上のボタンへ移した(E16-02)。実機で利用者が確認し、問題なし。

## 想定外だったこと
- 「腰」がどの部位か(脇腹か骨盤か)が言葉だけでは決まらず、最初に確かめた。脇腹の操作を骨盤の関節へ移すと、みぞおちを動かす手段がなくなることにも、設計の途中で気づいた
- 新しいテストの準備の誤り(比べる側の人形が頭を選んだまま)で2件が落ちた
- Python で書き換えたファイルの改行が CRLF になった(Windows のテキストモード)。コミットの前に LF に戻した

## 次に活かすこと
- 部位の呼び名(腰・お腹など)は、アプリの部位名に置き換えて確かめてから進める
- 操作の支点を移すときは、移した先だけでなく、移した元の関節をどこで動かすかも一緒に決める
- 「選んだ部位」と「状態を変える関節」を分けておく(`guideJoint`)と、根による操作の違いを1か所で扱えた
- Python でファイルを書き換えるときはバイナリで読み書きし、改行を変えない
