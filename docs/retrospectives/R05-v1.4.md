# R05 v1.4.0(2026-11-15)

使ってみる期間に出た要望4件(E14: 頭の位置・胸の上端の切り口・胸と脇腹と骨盤の長さ・骨盤が根のときの操作)を入れた。実機で利用者が確認した。

## 想定外だったこと
- 独立したタスク(E14-04)を別の worktree で並行に進めたが、エミュレータは1台を共有していたので、相手のインストールが自分の画面の確認の途中に割り込んだ。見た目の確認は相手が終わってからまとめて行った
- `git add -A` で、作業用 worktree のフォルダをリポジトリに登録してしまった(.gitignore に無かった)。外して無視するようにした
- worktree を消すとき、ビルドの出力のパスが長すぎて Windows で消し切れなかった
- 胸の切り口のテストで、前の縁を「x = 0・z > 0 の頂点」で選んだら、ふたの真ん中の頂点が混ざった

## 次に活かすこと
- 並行のタスクでは、エミュレータでの確認を片方ずつにする(並行する側にはエミュレータを使う時間を短くするよう伝えるだけでは足りない)。必要ならエミュレータを2台にする
- コミットは対象のパスを指定して add する(`git add -A` を使わない)
- 形のテストで頂点を選ぶときは、面の頂点とふたの頂点が混ざらない条件にする
