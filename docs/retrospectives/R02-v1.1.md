# R02 v1.1.0(2026-11-14)

v1.0.0 を触ってもらって出た要望を、E07〜E11(体型・体の形・初期姿勢・根の切り替え・影)にまとめて入れた。v1.0.0 と同じ日に出した。実機での確認はリリースのあとに行う(利用者の判断)。

## 想定外だったこと
- 根の切り替え(E10-01)で、最初の設計(範囲と玉を骨盤の関節に点対称で出す)が間違っていた。骨盤を止めると、骨盤とまっすぐつながる脇腹も止まり、動くのはみぞおちを支点にした胸だけだった。方向を確かめるテストが失敗して気づき、設計を改めた
- 自然な姿勢(E09)を「置くとき」だけに入れたため、置く前の半透明の影がまっすぐのままで、置いた瞬間に角度が変わった。利用者の指摘で直した。「未検証」に書いて残していたが、そのまま完了にしていた
- テストを先に書いたのに、失敗するのを確かめる手順を1回飛ばした(E08-02)
- シェルのヒアドキュメントでバックスラッシュや終わりの印が崩れ、Kotlin の文字列が壊れたり、スクリプトが実行されなかったりした。スクリプトをファイルに書いてから実行するようにした
- 部位を足す・スライダーを足すたびに、部位の数やスライダーの並びを数える既存のテストを直すことになった

## 次に活かすこと
- 向きや支点がからむ操作は、作る前に「何が止まり、何が動くか」を書き出してから設計する
- 「未検証のまま残したこと」に操作の違和感が出そうなもの(見た目が飛ぶ・ずれる)を書いたら、完了にする前に直すか利用者に聞く
- Red の確認は省かない
- 長い置き換えはヒアドキュメントではなく、スクリプトを Write でファイルにしてから実行する
- 実機での確認をため込まない。v1.1.0 は実機での指摘を受けて直す前提で、次はまず実機に入れる
