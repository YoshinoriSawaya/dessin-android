# R01 v1.0.0(2026-11-14)

Web版(three.js)を Android(Kotlin)に移し、ポーズの保存を加えた最初のリリース。2026-11-10 に始め、4日で出した。

## 想定外だったこと
- 移植の正しさは Web版との照合テストで確かめられたが、実機で触ると形と可動の指摘がすぐ出た(足の付け根、首の位置、肋骨の分割、もも・手・ひざ)。照合は「Web版と同じ」を保証するだけで、「人形として自然」は保証しない
- 実機の指摘で仕様が Web版から離れたため、照合テストは v1 の途中で止めることになった
- テストが失敗したままの WIP コミット(E04-02)が、マージで main の履歴に入った。中断するときの残し方を決めていなかった
- CHANGELOG の「未リリース」に同じ項目が二重に入っていた。並行のブランチをマージしたときに重なったとみられる。リリースの整理で直した

## 次に活かすこと
- 形や可動の変更は、テストが通った時点で早めに実機へ入れ、利用者に触ってもらう(エミュレータの見た目だけで締めない)
- 仕様の変更は Issue ごとにテストを書く(照合テストに頼らない)
- 並行のブランチをマージしたら CHANGELOG の重なりを確かめる
- 作業を中断するときは、失敗するテストを含むコミットをマージしない(WIP のブランチのまま残す)
- 体型の調整パラメータ(頭の大きさ・肩幅など)はすでにある。E07 はこれを土台にする
