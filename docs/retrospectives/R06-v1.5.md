操作中でない人形を人形のモード中に淡く描くようにし(E13-05)、止めていた照合テストと生成の道具を片付けた(E04-04)。淡く描く方は実機で利用者が確認した。

## 想定外だったこと
- 見せ方の質問で「人形のモード中だけ淡く」と「表示に切り替えを足す」を別々に聞いたら、組み合わせの意味が2通りに取れて、聞き直すことになった
- 画面の状態の項目を1つ足しただけで、古い形を作るテスト(影)の準備が合わなくなった。項目の数を決め打ちにしていた
- debug 起動の指定(`--es demo ...`)が、アプリが動いたままだと前の画面に渡されて効かないことがあった。止めてから起動し直すと効いた

## 次に活かすこと

- 古い形のデータを作るテストは、「ある位置より後ろを消す」のように項目の数に依存しない作り方にする
- エミュレータで起動時の状態を指定するときは、`am force-stop` してから `am start` する
