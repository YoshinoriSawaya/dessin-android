# R11 v1.10.0(2026-11-19)

プリセットのポーズを9つ入れた(E19-01)。各部位の狙いの向きと胸の前傾で定義し、自然な姿勢と同じ `aim` で当てる。実機で利用者が確認し、問題なし。

## 想定外だったこと
- 肘・ひざを狙いどおりに曲げるためのひねりの探し方が、立ち姿勢でもすねを数度寄せるためにももを大きくひねり、足が横を向いた。ひねりの大きさに重みを付けて直した
- しゃがむ・体育座り・あぐらで、ももの可動域(前 120°・外 70°)を超える狙いを置いていた。胸の前傾も可動域の基準を動かすことを見落としていた
- 姿勢は目で見ずに数値で決めたので、テストで確かめられるのは可動域に収まることまでだった

## 次に活かすこと
- 姿勢を数値で決めるときは、先に「狙いからのずれ」を全部位まとめて出す診断を回し、可動域の外の狙いを見つけてから直す
- ひねりのように自由度を探して決める値には、小さいほうを好む重みを付ける
