# R07 v1.6.0(2026-11-15)

人形の変更を戻す・やり直す Undo(E15-01)と、選んだ部位とその先を反対側へ鏡写しにするコピー(E15-02)を入れた。実機で利用者が確認した。

## 想定外だったこと
- 最初の質問(Undo の範囲・ボタンの位置・コピーの範囲と向き)は一度断られ、選択肢を出し直して答えてもらった
- コピーのボタンの文言「反対側へコピー」が長く、部位の行の名前が「左つま…」と切れた。「右へコピー」「左へコピー」に短くし、見出しも折り返さないようにした
- 手の形を写す処理が、手でない部位でも呼ばれて例外になった

## 次に活かすこと
- 部位の行にボタンを足すときは、いちばん長い部位の名前(左つま先など)で表示を確かめる
- 部位の種類で使えるものが違う操作(手の形など)は、全部位を回すテストで呼び分けを確かめる
- 画面の状態の書き換えを1か所(委譲)に集めておくと、Undo のような横断的な記録を後から足しやすかった
