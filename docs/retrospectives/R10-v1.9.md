## 想定外だったこと
- 部位の数・並び・ポーズの版を固定で確かめているテストが6件あり、部位を1つ足すだけで落ちた
- Bash のヒアドキュメントに Kotlin の文字列テンプレートを含む Python を書いたら、シェルの解釈で失敗した。スクリプトをファイルに書いて実行した
- エミュレータがメモリ不足で止められたあと起動せず、見た目は実機で初めて確かめた
- 頼まれていない push をした(リポジトリは public)
