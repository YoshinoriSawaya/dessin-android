# アーキテクチャ

## 構成(仮決定)
| 層 | 技術 | 備考 |
|----|------|------|
| UI | Jetpack Compose | スライダー、部位チップ、表示切替、回転オーブ、ダイアログ |
| 3D描画 | GLSurfaceView + OpenGL ES 3.0 | 円柱・箱・球・旋盤体・管・半透明の可動域・シャドウマップ |
| ロジック | 純Kotlin(Android非依存) | JVMテスト対象。`:core` モジュールに分け、Android API を使えないようにする |

3D描画の代替案(Filament / SceneView、libGDX、Godot C#)は検討済み。Android標準で枯れている点を理由に OpenGL ES を仮採用し、v1.0〜v1.2 はこの構成で作った。

### モジュールとパッケージ
- `:core`(純Kotlin)
  - `math` ベクトル・四元数・行列・レイ
  - `skeleton` 部位の定義(`PartSpecs`)・可動域・骨格(`Skeleton`)・体型(`BodyParams`)・手の形・根
  - `mesh` 部位の形(`PartVisuals`)・可動域の表示・格子
  - `camera` 軌道カメラ
  - `pick` ピッキング(部位・玉・緑の範囲・人形)
  - `render` 何をどう描くか(`drawPlan`)・影の範囲
  - `editor` 画面の状態(`EditorState`)・スライダー・指の操作・自然な姿勢・画面の状態の保存
  - `pose` ポーズ・体型・場面の保存形式と、名前を付けて保存する一覧
- `:app`(Android)
  - `ui` Compose の画面・パネル・ダイアログ
  - `gl` GL の描画(シェーダ・シャドウマップ)と指のイベント
  - `storage` 保存の置き場所(アプリ専用のフォルダのファイル)
  - `DebugStart.kt` デバッグビルドだけの起動時の状態の指定(`docs/development.md`)

## 対象環境
- minSdk 26(Android 8.0)、OpenGL ES 3.0
- 画面は縦向きに固定
- 部位同士の衝突判定は行わない(めり込みを許す)

## ロジック層の仕様(v1 で Web版から移植)
- 部位は親の関節グループの子。各部位に休止方向 a0、基準フレーム Qb、状態 {phi, psi, roll} を持つ
- 基準フレームでの方向: d' = (sinφ·sinψ, −cosφ, −sinφ·cosψ)
- 回転: Qb · swing(rest→d') · roll(軸 (0,−1,0)) · Qb⁻¹
- 可動域: 4象限の楕円コーン {前, 後, +x, −x} の角度制限。右側は ±x を入れ替え、ロールは鏡像
- ヒンジ: ψ固定、φは範囲制限。肘(ψ π、−15〜150°)、ひざ(ψ 0、0〜150°)、つま先(ψ π、−30〜60°。正で上へ)
- 入力→状態: 画面上のドラッグを可動域内の方向に変換(レイ×球交点)。回転オーブはスイング・ツイスト分解で可動域とロール範囲にクランプ
- 親を置き直すと子孫が追従する

## 部位と関節
部位は23個。置く順序(親から子):

胸 → (肩L/R、首、脇腹) → (上腕、頭、骨盤) → (前腕、股関節の付け根) → (手、もも) → すね → 足 → つま先

- 胸と脇腹は、もとの肋骨(高さ 0.30)を上から 6.5:3.5 に分けたもの(E05)。脇腹の関節は分かれ目の背骨の線(前後 −0.035)、可動域は前 25°・後ろ 20°・左右 20°、ひねり ±30°
- 首の付け根と脇腹・骨盤の関節は背骨の線(前後 −0.035)に置く(E04-03)。首の付け根の前後は体型で変えられる
- 足の付け根(股関節の付け根)は骨盤の側面から少し見える円柱にし、骨盤の脚の付け根の近くのタップでも選べる(E04-02)
- もものひねりは ±90°。手は平たい面が体側を向き、手首は手の平・甲の側に 60°・親指・小指の側に 25°。ひねり(回内・回外)は前腕で ±90°、手はひねらない(E06-01)
- ひざは大腿骨の丸みの中心(既定は関節の 0.03 上)で回り、曲げるとすねの付け根が後ろ上へ移る(部位の定義の pivot。E06-02)。ずれの大きさは体型で変えられる
- つま先は足の子で、関節は足の前の付け根(E08-03)

## 体の形
- 胸は肋骨のように、中ほどが最も広く上下が狭まる旋盤体(E08-01)。上端は首側を斜めに切る(後ろの中央が最も高く、前へ 25°・肩へ 15° 下がる。E14-02)
- 手の形はパー(扇状の指)とグー(ブロック)を差し替える。指の関節は作らない。親指は前に付く。左右別々で、ポーズに保存する(E08-02)
- 足はかかとを丸める。つま先は別の部位(E08-03)
- 頭の形は首の軸より前へ 0.025(頭の関節の空間)ずらして置く(E14-01)
- 乳房は胸の前面に付き、大きさは体型(0 なら描かない)。性器は骨盤の前の下に付き、形は体型の性別で切り替える(E08-04)
- どのメッシュを描くか(手の形・乳房・性別)は `PartVisuals.isShown` にまとめ、描画・ピッキング・全体を表示が従う

## 体型
- 項目: 頭の大きさ(基準は v1 の 70%。E07-01)、肩幅、骨盤の横幅、股関節の付け根の内寄り、胸・脇腹・骨盤の長さ(E14-03)、首の長さ、首の付け根の前後、上腕・前腕・もも・すねの長さ(左右共通)、身長、ひざの転がりのずれ(E07-02)、乳房の大きさ・性別(E08-04)
- 長さ(胸・脇腹・骨盤も。E14-03)の倍率は部位の形を縦に伸ばし、子の取り付け位置(縦だけ)と可動域の表示の半径もそれに従う。乳房と性器は位置だけが動く。身長は根の拡大率に掛かり、胸の大きさ(ポーズ側)と掛け合わさる
- 体型はポーズと別に持ち(E07-03)、人形ごとに別(E13)。ポーズを読み込んでもいまの体型を保つ。部位を外しても体型は変わらない
- 調整は部位を選んだときのスライダーで行う(性別は骨盤を選んだときの行)
- 既定の体型(E07-04。`DefaultBody`): 保存した体型から1つ選べる。選んでいなければ `BodyParams()`。起動したとき・人形を足したとき・「既定の体型に戻す」で使い、場面の読み込みでは使わない

## 姿勢と操作
- 自然な姿勢(E09。`NaturalPose`): 部位を置いたとき・「向きを戻す」・置く前の半透明の影は、首は前へ 15°・頭は傾きなし、脇腹は前へ 10°(胸が前)・骨盤は傾きなし、付け根は下へ 20°・ももは外向き 5°。可動域の基準(0°)と骨格の休止状態はまっすぐのまま
- 根(E10-01): データはいつも胸を根に持つ。骨盤が根のときは、脇腹を動かすたびに骨盤が止まるよう胸の置き方を補正する(みぞおちを支点に胸が動く)。そのときの脇腹の玉は胸の上向き、範囲は脇腹の向きで上下を反転して出し、脇腹のひねりのスライダーは符号を逆にして見せる(+ で上半身が、胸が根のときの骨盤と同じ向きに回る。E14-04)。骨盤が根のときの骨盤は胸と同じく全体を操作する(E14-04。`Skeleton.isAnchorRoot`): ドラッグで全体を動かし、回転オーブと傾きの3本のスライダー(骨盤のワールドの向き)で骨盤の関節を中心に全体を回す(胸の置き方を回す)。緑の範囲は出さない。根は保存しない
- 指の操作(`TouchGesture`): 1本指は選択中の部位を押していれば向きを決め(胸なら動かす)、それ以外は視点を回す。2本指はピンチ。タップで部位を選び、緑の範囲の2回タップでその点へ向ける
- カメラだけを操作するモード(E12): 部位を拾わず、1本指で回転・ピンチで拡大縮小・2本指の真ん中の動きで平行移動(注視点を動かす)
- マウスホイール(E12-02): 一刻みで距離を 0.9 倍(上へ回すと近づく)。モードによらない
- 複数の人形(E13): 場面に10体まで。操作中の人形を `EditorState.skeleton`、ほかを `others` に持ち、今までの操作は操作中の人形に効く。ふだんはほかの人形を触れない。人形のモード中は指の動きがカメラのモードと同じになり、タップした人形に切り替える

## 描画
- 描く順序: 不透明な部位(操作中の人形 → ほかの人形)→ 半透明の影(置く前の部位、奥から)→ 可動域・縁・玉(奥行きを見ずに手前へ)
- ほかの人形は置いた部位だけを描く(選択の色・半透明の影・可動域なし。`otherDollPlan`)。人形のモード中で「ほかを淡く」がオン(既定)のときは、不透明のまま紙の色に寄せて淡く描く(E13-05)
- 陰影は Web版の材質の拡散反射を近似(半球光 0.75・平行光 0.85)
- 体に落ちる影(E11): 太陽(陰影と同じ向き)から見た正射影のシャドウマップ(2048)に、全員の置いた部位の奥行きを書き、影の中では平行光の分を消す。床には落とさない。表示の「影」で切り替える

## 保存
| 何を | 形式 | 置き場所 |
|------|------|----------|
| ポーズ(1体) | `PoseCodec`(版3: `root`・`part`・`hand` の行。版1・2の `body` の行も読む) | 今は場面の一部として使う |
| 体型 | `BodyCodec`(「名前=値」を並べた1行。知らない名前は読み飛ばす) | `files/bodies/<id>.body` |
| 既定の体型 | 既定にした体型の id(1行) | `files/settings/default-body.setting` |
| 場面 | `SceneCodec`(人形ごとに `doll`・`bodytype`・ポーズ) | `files/poses/<id>.pose` |
| 画面の状態 | `EditorStateCodec`(選択・視点・表示・モード・根・人形の並びと、操作中の人形のポーズ) | Compose の状態の保存(画面の作り直しと、裏にある間のプロセスの終了では残る。利用者がアプリを閉じると消える) |

- 名前を付けて保存したファイルは `dessin-saved 1`・名前・時刻・種類(`scene`・`pose`・`body`)・中身の順。場面の一覧は v1.0 で保存した `pose` のファイルも読み、読み込むと操作中の人形に入れる(`SceneLibrary`)
- 読み込みの失敗は結果型で返し、理由はログ、利用者には短い文言だけを出す
- 根(胸・骨盤)はポーズにも場面にも保存しない

## 参照実装
v1 までは Web版 `docs/web-reference.html`(three.js r128、単一HTML)を参照実装とし、寸法・可動域・操作の規則を移植して照合テストで一致を確かめた。Web版は今後使わない(2026-11-11)。v1 以降の仕様は、この文書と Android 版のコード(`:core` の `PartSpecs` など)を正とする。
