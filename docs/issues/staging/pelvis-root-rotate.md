# 下書き: 骨盤が根のとき、回転オーブで全体を回す

## 要望(2026-11-14、利用者)
- 胸を根にしているときは、胸を回転オーブで回すと全体が回る(正しい)
- 骨盤を根にしているときは、骨盤を回転オーブで回すと骨盤の角度だけが変わる(間違い)
- 骨盤を根にしているときは、胸と同様に、骨盤を回すと全体が回るべき

## 関連
- E10-01(根の切り替え)。今は骨盤が根でも、骨盤そのものの操作は今までどおり(骨盤と脚だけが動く)で、E10-01 の「未検証のまま残したこと」に書いていた
- データはいつも胸を根に持ち、骨盤が根のときは胸の置き方を補正して骨盤を止めている。全体を回すには、骨盤を中心に人形全体(胸の置き方)を回す形になる見込み
