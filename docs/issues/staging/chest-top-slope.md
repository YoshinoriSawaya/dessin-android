# 下書き: 胸の上端(首側)を斜めに切る

## 要望(2026-11-14、利用者)
胸の形だが、首側を斜めに切れないか

## 関連
- E08-01(胸を肋骨の形にした)。今の胸は、上端が水平に切れた旋盤体(上端 y = 0.15、半径 0.085)
- 上端を斜めにすると、首の付け根・肩の付け根・胸の線(縦線と輪)・乳房の位置との関係も見直す

## 確認したいこと
- 斜めの向き: 前(鎖骨のくぼみの側)が低く、後ろ(首の付け根の背骨の側)が高い、でよいか(実際の胸郭の上の口に近い向き)。それとも左右(肩に向かって下がる)か
- 角度の目安(例: 20〜30°)
- 胸の長さの調整(torso-length.md)と一緒に進めるか
