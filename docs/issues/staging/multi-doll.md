# 下書き: 複数の人形を同時に置く

## 要望(2026-11-14、利用者)
複数人を同時に画面に置けるようにしたい

## 関連
- いまは人形が1体で、骨格(`Skeleton`)・選択・ポーズの保存がすべて1体を前提にしている。データの持ち方から変わる大きな変更

## 確認したいこと
- 何体まで置けるとよいか(2〜3体の構図か、それ以上か)
- 人形の追加・削除・切り替えの操作(どの人形を操作しているかの示し方)
- 体型は人形ごとに別にするか
- 保存: ポーズの保存は全員まとめて(場面として)か、1体ずつか
- 人形どうしの位置関係の決め方(胸のドラッグで動かす、で足りるか)
- 影は人形どうしにも落とすか
