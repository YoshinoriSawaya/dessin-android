# 下書き: 腰と胸の長さの調整

## 要望(2026-11-14、利用者)
- 腰の長さを調整できるとよい
- 胸の長さを、身長とは無関係に調整できるとよい

## 関連
- E07-02(体型の項目)。首・上腕・前腕・もも・すねの長さは体型の項目で、部位の形を縦に伸ばし、子の取り付け位置と可動域の表示もそれに従う。同じ仕組みで足せる見込み
- 身長は人形全体の拡大(胸の拡大率に掛かる)で、胸の長さとは別
- 胸は肋骨の形の旋盤体(E08-01)。縦に伸ばすと、首・肩・脇腹の取り付け位置と、乳房の位置も合わせて動かす必要がある

## 確認したいこと
- 「腰」はどの部位か: 脇腹(胸と骨盤の間。今の高さは 0.105)か、骨盤(高さ 0.14)か、その両方か
- 胸の長さを変えたとき、肩の付け根の高さも一緒に動かすか(胸の上端に合わせる)
- 範囲(ほかの長さと同じ 70〜130% でよいか)
- どの部位を選んだときにスライダーを出すか(胸なら胸を選んだとき、腰なら脇腹か骨盤を選んだとき)
