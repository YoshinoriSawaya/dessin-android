# 下書き: 頭が後ろ過ぎる

## 要望(2026-11-14、利用者)
頭が後ろ側過ぎるように感じる

## 関連
- E04-03 で首の付け根を背骨の線(前後 −0.035)へ移した(利用者の指摘「もう少し後ろ」)。その上に頭が乗る
- E07-01 で頭を 70% に小さくし、E09 で首を前へ 15° 傾け頭を戻した(自然な姿勢)。頭が小さくなったぶん、首の付け根に対して後ろ寄りに見えている可能性がある
- 首の付け根の前後は、今も体型の項目(首を選んだときの「付け根の前後」、既定 −35mm)で動かせる

## 確認したいこと
- 直し方:
  - 首の付け根の前後の既定を前へ寄せる
  - 首の付け根はそのままで、頭の球を首に対して前へずらす(頭の形の置き方を変える)
  - 自然な姿勢の首の前傾を大きくする
- どの視点で後ろ過ぎると感じるか(横から見たとき、など)。スクリーンショットがあると決めやすい
