# 下書き: 保存した体型から既定の体型を選ぶ

## 要望(2026-11-14、利用者)
- 保存されている体型の中から、既定(デフォルト)の体型を選べるようにしたい

## 関連
- E07-03(体型の保存)。体型は BodyLibrary に1件1ファイル(.body)で保存し、「保存した体型」の一覧から読み込むと操作中の人形に入る(loadBody)
- 今の既定の体型は BodyParams() の固定の値。次の場所で使う
  - 初めて起動したとき(Skeleton.initial → NaturalPose.initial)。画面の状態は保存して戻すので、2回目以降の起動は前回の体型のまま
  - 人形を足したとき(EditorState.addDoll が NaturalPose.initial を置く。E13-02)
- 既定の体型を覚えておく場所が要る(どの id を既定にしたか)。体型のファイルとは別に持つ見込み。既定にした体型を消したら、固定の値に戻す

## 確認したいこと
- 既定の体型を使う場面: 人形を足したとき・初めて起動したときのほかに、「体型を既定に戻す」操作も欲しいか
- 既定を選んだとき、今いる人形の体型も変えるか(変えない案: 次に足す人形から効く)
- 選び方: 「保存した体型」の一覧の各行に「既定にする」を置き、既定の行に印を付ける案でよいか。既定を外して固定の値に戻す操作も要るか
- 場面を読み込んだときは、場面に保存された体型のまま(既定で上書きしない)でよいか
