# E17-04 扇形の可動域表示

親: [E17](../epics/E17-knee-structure.md)

## 概要
- すねの可動域の表示を、曲げる面の扇から、曲げ角 θ を半径方向・ひねり φ を角度方向にした扇形の面にする。曲げるほど扇が広がる
- 面は、曲げる面の扇を、ももの軸のまわりに φ だけ回した点の集まり。玉もいまのひねりの分だけ回した位置に出す
- 玉のドラッグと範囲の2回タップは、いまのひねりの分を戻してから曲げ角を求める(ひねりはスライダーだけで変える)

## 進め方
面と玉の位置は `:core` でテスト先行。見た目はエミュレータと実機で確かめる

## 完了条件
- 扇の幅が曲げ角に応じて広がること、ひねっていても玉のドラッグで曲げ角が飛ばないことをテストで確かめる
