# E17-04 扇形の可動域表示

親: [E17](../epics/E17-knee-structure.md)

## 概要
- すねの可動域の表示を、曲げる面の扇から、曲げ角 θ を半径方向・ひねり φ を角度方向にした扇形の面にする。曲げるほど扇が広がる
- 面は、曲げる面の扇を、ももの軸のまわりに φ だけ回した点の集まり。玉もいまのひねりの分だけ回した位置に出す
- 玉のドラッグと範囲の2回タップは、いまのひねりの分を戻してから曲げ角を求める(ひねりはスライダーだけで変える)

## 進め方
面と玉の位置は `:core` でテスト先行。見た目はエミュレータと実機で確かめる

## 完了条件
- 扇の幅が曲げ角に応じて広がること、ひねっていても玉のドラッグで曲げ角が飛ばないことをテストで確かめる

## 検証結果
- テスト先行: `KneeFanTest` を書き、玉の位置と扇の形の2件が失敗するのを確認してから実装した(`guideDir`・`dotPosition`・`guideMesh` の扇)
- 実装の途中で、ひねった状態で曲げる面の上の向きへ向けると曲げ角がずれた(`KneeRotationTest` の1件が失敗)。扇は曲げ角が半径方向なので、ドラッグでは軸からの角度を曲げ角にする形に直した(テストは変えていない)
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(:core のテスト487件、失敗0件・止めているもの0件。lint は既存の警告5件のみ)
- エミュレータ: 左すねを選び、扇がももの軸のまわりに広がって表示され、玉がひねりの分だけ外へ寄った位置に出ることを見た

## 未検証のまま残したこと
- 実機でのドラッグの操作感(扇の外側を触ったときの動き)
- 範囲の面を2回タップしても、ひねりは変わらない(曲げ角だけ)。ひねりも変えたいという要望が出たら検討する
- 利用者による実機での確認はまだ
