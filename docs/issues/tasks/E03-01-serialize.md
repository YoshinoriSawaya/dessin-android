# E03-01 ポーズの直列化

親: [E03](../epics/E03-pose-save.md)

## 概要
骨格の状態(肋骨の位置・回転・大きさ、各部位の配置の有無・φ・ψ・roll、調整パラメータ)を文字列に変換し、元に戻す。純Kotlin。読み込み時は範囲外の値をクランプする。

## 完了条件
- 保存して戻すと同じ姿勢になる
- 壊れたデータや範囲外の値の扱いのテストが通る

## 依存
E01-08, E01-09

## 設計の決定
- 形式は JSON ではなく、版番号付きの行形式のテキストにした(`:core` に JSON の依存を増やさないため)。先頭行は `dessin-pose 1`。形式を変えるときは版番号を上げる
- 数値は Kotlin の Double の文字列表現で書き、読み戻すと同じ値になる(保存して戻すと Skeleton が完全に一致する)
- 読み込みの結果は `PoseDecodeResult`(Ok か Error)で返し、例外は外に出さない。Error の理由は内部ログ向け
- 形式の誤り(見出し・版番号・項目の数・数値でない・有限でない・知らない行)はエラー。値の誤りは範囲に収める: 状態は可動域(ヒンジは曲げる向きを固定)、体型と肋骨の大きさはスライダーの範囲、肋骨の回転は正規化(長さ0なら回さない)
- 書かれていない値は初期値、知らない部位の行は無視、親が置かれていない部位と置いていない部位は外した扱い(休止状態)にする
