# E10-01 根の切り替え(胸/骨盤)

親: [E10](../epics/E10-controls.md)

## 概要
- 初期設定では胸を根にするが、操作中に骨盤を根にできるようにする(2026-11-14、利用者)
- いまは脇腹を曲げると下半身ごと動く(E05-02)。骨盤を根にすれば、下半身を残して上半身を曲げられる

## 確認したいこと
- 切り替えの操作(ボタンで切り替える/選んだ部位で自動に決まる など)
- 切り替えたときに人形がその場から動かないこと(見た目の姿勢を保つ)
- 根の選択をポーズに保存するか

## 進め方
根の付け替えの計算は `:core` でテスト先行。操作は手動確認

## 完了条件
- 根を切り替えても全部位のワールドの姿勢が変わらないテストが通る
- 実機で切り替えて操作できる
