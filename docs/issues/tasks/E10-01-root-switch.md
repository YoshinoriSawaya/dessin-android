# E10-01 根の切り替え(胸/骨盤)

親: [E10](../epics/E10-controls.md)

## 概要
- 初期設定では胸を根にするが、操作中に骨盤を根にできるようにする(2026-11-14、利用者)
- いまは脇腹を曲げると下半身ごと動く(E05-02)。骨盤を根にすれば、下半身を残して上半身を曲げられる

## 決まったこと(2026-11-14、利用者)
- 骨盤が根のときの脇腹の操作(緑の範囲・玉・回転オーブ)は、上半身を動かす向きにする
- 根の切り替えは、脇腹を選んでいるときだけ「根」の行(胸・骨盤)で行う
- 根はポーズに保存しない(画面の状態としては残す)

## 進め方
根の付け替えの計算は `:core` でテスト先行。操作は手動確認

## 完了条件
- 根を切り替えても全部位のワールドの姿勢が変わらないテストが通る
- 実機で切り替えて操作できる

## 依存
なし

## 設計の決定
- 骨格に `anchor`(胸・骨盤)を持つ。データはいつも胸を根に持ち、骨盤が根で骨盤を置いているときは、脇腹の状態を変えるたびに骨盤のワールドの位置と向きが変わらないよう胸の置き方(位置と回転)を補正する(`Skeleton.withState`)。aim・ドラッグ・回転オーブ・向きを戻すはすべてここを通る
- 骨盤が止まると、骨盤とまっすぐつながる脇腹もワールドで止まる。動くのは、脇腹の関節(みぞおち)を支点にした胸(胸が根のときと同じ関節で、止まる側が入れ替わる)
- 骨盤が根のときの脇腹の表示: 中心は脇腹の関節のまま。玉は胸の上向きの方向、緑の範囲は脇腹の向きに置いて上下を反転する(胸の上向きが取れる範囲になる)。`Skeleton.guideMatrix` にまとめ、描画とピッキングが使う
- ドラッグ・2回タップは胸の上向きとして受け取り、脇腹の状態に直す。回転オーブは胸をその回転で回す(脇腹には逆の回転を加え、補正で胸が回る)
- 根はポーズに保存しない。保存したポーズを読み込んでもいまの根を保つ。画面の状態(`EditorStateCodec`)には `anchor` の行で残す
- 画面: 脇腹を選んでいて骨盤を置いているときだけ「根」の行を出す

## 検証結果
- テスト先行: `AnchorTest`(既定・骨盤が止まる・骨盤なしなら胸と同じ・玉と範囲・ドラッグ・回転オーブ・保存しない・根の選択)を書き、未定義でコンパイルが通らないことを確認してから実装した
- 最初は緑の範囲と玉を骨盤の関節に点対称で出す設計にしたが、方向のテスト2件が失敗した。調べると、骨盤を止めると脇腹も止まり、動くのはみぞおちを支点にした胸だけだったので、上の設計に改めた。あわせて、新しく書いたテストのうち範囲の中心を骨盤に置く前提のものと、回転オーブのテストにあった胸が根のときの向きの想定(逆だった)を書き直した。既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト345件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37、`--es demo natural --es select flank`、横から): 「根」の行が出る。骨盤にすると玉が胸の上向きの位置へ移る。玉を前へドラッグすると、骨盤と脚はその場のまま、上半身がみぞおちから前へ倒れる。クラッシュなし

## 未検証のまま残したこと
- 実機での操作感
- 骨盤が根のときの脇腹のひねり(スライダー)は、胸が根のときと同じ向きの値のまま(胸が逆向きにひねれる)
- 骨盤そのものの操作は、骨盤が根でも今までどおり(骨盤と脚が動く)
- 身長や胸の大きさを変えたときは骨盤も動く(補正は脇腹の状態を変えたときだけ)
