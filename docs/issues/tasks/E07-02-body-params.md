# E07-02 体型のデータと調整

親: [E07](../epics/E07-body-type.md)

## 概要
- 体型を表すデータを作り、画面から調整できるようにする
- 項目に入るもの(2026-11-14、利用者): 首の長さ、頭の大きさ(E07-01 の 70% を基準にする)
- v1 にはすでに体型の調整パラメータ(頭の大きさ・肩幅・骨盤の横幅・付け根の内寄り、スライダーで調整)がある。これを土台にして項目を足す

## 確認したいこと
- 調整できる項目を、ほかに広げるか(身長・肩幅・手足の長さなど)
- 「首の付け根の位置の調整」(次のフェーズの候補だったもの)をこの項目に含めるか
- ひざの転がりのずれ(E06-02 の 0.03)を体型の項目に含めるか(E10-02 を参照)
- 調整の操作(スライダーなど)と、それを出す場所

## 進め方
体型から骨格への反映は `:core` でテスト先行。画面は手動確認

## 完了条件
- 体型を変えたとき骨格・玉の位置が正しく追従するテストが通る
- 実機で調整できる
