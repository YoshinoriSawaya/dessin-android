# E02-06 画面の状態と操作パネル

親: [E02](../epics/E02-render-ui.md)

## 概要
- 画面の状態(Skeleton、選択中の部位、表示の切替、カメラ)を1か所で持つ。操作は状態を新しくして描画を要求する
- 選択中の部位の名前と説明、部位チップ(配置の段ごとに区切る。置いた・置ける・置けないの見た目)、外す・向きを戻すボタン、パネルの折りたたみ
- 外したら親を選ぶ(Web版の del の処理)

## 進め方
状態管理は JVM テスト、見た目は手動確認

## 完了条件
- 部位チップからの選択・配置・外す・向きを戻すが状態に正しく反映されることをテストで確かめ、エミュレータで見た目を確かめる

## 依存
E01-08

## 設計の決定
- 画面の状態(`EditorState`: 骨格・選択中の部位・視点・表示の切替・パネルの開閉)と操作(選ぶ・外す・向きを戻す・折りたたむ)、部位チップの並びと見た目、説明文を `:core` の `editor` パッケージに置いた(テスト先行)
- 状態の保持に ViewModel(依存の追加)は使わず、`EditorStateCodec` で文字列にして Compose の `rememberSaveable` で保存する。依存が増えず、画面の作り直しにもプロセスの終了にも耐える。読み込めなければログを残して初期状態から始める
- 操作パネル(`ControlPanel`)は Web版の CSS(色・大きさ・チップの枠: 選択中は塗り、置いた部位は濃い枠、置ける部位はアクセント色の点線、置けない部位は薄く)に合わせた。「表示」の段には仮に視点の4つのボタンを置く(E02-10 で整える)。スライダーとオーブは E02-08・E02-09
- 起動時の状態の指定(デバッグビルド)は `EditorState` を返すようにした
- 画面は常に明るい配色なので、システムバーのアイコンは常に暗い色にした(夜間モードで見えにくくなるため)

## 検証結果
- テスト先行: `EditorStateTest`(12件)・`EditorStateCodecTest`(4件)を書き、コンパイルエラーで失敗することを確認してから実装した
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト208件成功、lint は 0 errors、既存の警告5件のみ)
- エミュレータ(AssetDash_API37、Android 17)で確認(Claude が adb で操作):
  - 起動: 肋骨が選択中(塗り)、置ける4部位が点線、「外す」は押せない、説明文は肋骨用
  - 「首」のチップ: 首が置かれて選択中になり、説明文が変わり、「外す」が押せ、肋骨のチップは濃い枠に。3D でも首が選択中の色、頭がゴースト、首の可動域が出る
  - 「外す」: 首が外れて肋骨が選ばれる
  - 折りたたみ: パネルが選択中の部位の行だけになり、ボタンが ▲ になる
  - 画面の作り直し(夜間モードの切替): 首の選択と折りたたみがそのまま残る
- 確認の途中で直したこと: パネルの下(ナビゲーションバーの部分)が灰色の帯になっていた(余白をパネルの色の外側に取っていた)。夜間モードでシステムバーのアイコンが白くなっていた

## 未検証のまま残したこと
- チップの横スクロール(画面の外の部位チップの操作)は手で確かめていない
- プロセスの終了からの復元(開発者向けオプションの「アクティビティを保持しない」などでの確認)はしていない。同じ保存の仕組みなので画面の作り直しと同じく戻るはず
