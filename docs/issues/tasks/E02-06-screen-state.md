# E02-06 画面の状態と操作パネル

親: [E02](../epics/E02-render-ui.md)

## 概要
- 画面の状態(Skeleton、選択中の部位、表示の切替、カメラ)を1か所で持つ。操作は状態を新しくして描画を要求する
- 選択中の部位の名前と説明、部位チップ(配置の段ごとに区切る。置いた・置ける・置けないの見た目)、外す・向きを戻すボタン、パネルの折りたたみ
- 外したら親を選ぶ(Web版の del の処理)

## 進め方
状態管理は JVM テスト、見た目は手動確認

## 完了条件
- 部位チップからの選択・配置・外す・向きを戻すが状態に正しく反映されることをテストで確かめ、エミュレータで見た目を確かめる
