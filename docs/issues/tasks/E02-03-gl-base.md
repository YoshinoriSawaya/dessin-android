# E02-03 GL描画の土台

親: [E02](../epics/E02-render-ui.md)

## 概要
- GLSurfaceView(OpenGL ES 3.0)を Compose の画面に載せる。画面の上が3D、下が操作パネル
- 光源つきの不透明シェーダと、半透明・常に手前に描くシェーダ(可動域・玉用)
- 背景色、床と格子
- Manifest に縦向き固定と OpenGL ES 3.0 を宣言する
- 描画は変化があったときだけ行う(Web版の dirty と同じ。RENDERMODE_WHEN_DIRTY)

## 進め方
`:app`(手動確認)

## 完了条件
- エミュレータで床と格子が見え、カメラのプリセットを切り替えると視点が変わる

## 依存
E02-01

## 設計の決定
- `DollSurfaceView`(GLSurfaceView、OpenGL ES 3.0、内容が変わったときだけ描く)と `DollRenderer` を `:app` の `gl` パッケージに置いた。UI のスレッドからは描く内容(Skeleton とカメラ)を丸ごと差し替えて requestRender する
- シェーダは2つ: 光の当たる面(Web版の半球光 0.75 と平行光 0.85 の拡散反射だけを近似。鏡面反射と影は省く。軸ごとの拡大があるので法線行列はシェーダで求める)と、単色(線・格子)
- シェーダのコンパイル・リンクに失敗したら、理由をログに出して例外にする(描画を続けられないため)
- 床の格子は three.js の GridHelper(6, 12) と同じ線を `:core` の `gridLines` で作る(テスト先行)。Web版の床は影だけを受ける面なので、影を入れるまで(E02-11)は描かない
- 画面は Compose で、上が3D、下が操作パネル。いまのパネルは視点の切り替えボタン(正面・横・背面・上)だけの仮のもの(E02-06・E02-10 で作り直す)
- 起動して画面の大きさが分かったら、置いた部位で全体を表示する(Web版の起動時の fitView)
- 描画の確認のため、置いた部位を基本の色で描く(色分け・可動域・玉は E02-04)
- Manifest に縦向き固定と OpenGL ES 3.0 を宣言した。縦固定は v1 の決定なので、lint の LockedOrientationActivity・DiscouragedApi はその activity に限って無視する

## 検証結果
- テスト先行(格子): `GridTest` を書き、コンパイルエラーで失敗することを確認してから実装した。GL の部分は手動確認
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト173件成功、lint は 0 errors、既存の警告5件のみ)
- エミュレータ(AssetDash_API37、Android 17)で起動(Claude が adb で確認):
  - 起動直後: 肋骨が画面中央に大きく表示され(全体を表示)、光の当たり方で立体に見える。正中線(赤)と輪郭線、床の格子が見える
  - 「上」を押すと真上からの視点に、「横」を押すと横からの視点に切り替わった
  - アプリのクラッシュとシェーダのエラーのログはなし
