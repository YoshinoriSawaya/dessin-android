# E16-02 根の切り替えを右上のボタンへ

親: [E16](../epics/E16-pelvis-root-chain.md)

## 概要
- 根を選択するボタンは、右上のカメラ等のボタンがある場所がよい(2026-11-15、利用者)
- いままで(E10-01)は、脇腹を選んでいて骨盤を置いているときだけ、操作パネルに「根」の行(胸・骨盤)を出していた

## 決まったこと(2026-11-15。細部は Claude が決め、利用者に報告)
- 右上の列(カメラ・人形・戻す・やり直す)の「人形」の下に、根のボタンを1つ置く。文言は「根: 胸」「根: 骨盤」で、押すたびに入れ替わる。骨盤が根のときは押した見た目(カメラ・人形と同じ)
- 骨盤を置いているときは、選んでいる部位によらず出す。骨盤を置いていなければ出さない
- 操作パネルの「根」の行はなくす

## 進め方
切り替えの規則は `:core` でテスト先行。ボタンの見た目は手動確認

## 完了条件
- 骨盤を置いていれば、どの部位を選んでいても根を切り替えられ、選んでいる部位は変わらないことをテストで確かめる
- 右上にボタンが出て、押すと根が切り替わる

## 設計の決定
- `EditorState.anchorChoice` を、骨盤を置いているときの今の根にした(脇腹を選んでいる条件を外した)。`toggleAnchor()` を足した
- 画面: `DessinScreen` の右上の列に `ToolChip("根: …")` を足し、`ControlPanel` の「根」の行と `PanelActions.onAnchor` を消した
- 根の切り替えは今までどおり人形の変更として Undo の1段になる(根は骨格が持つため)

## 検証結果
- テスト先行: `AnchorTest` の根を選べる条件のテストを、新しい仕様(どの部位でも切り替えられる・選んでいる部位は変わらない・骨盤が無ければ何もしない)に書き換え、`toggleAnchor` が未定義でコンパイルが通らないことを確認してから実装した。書き換えた理由は仕様の変更(脇腹を選んでいるときだけ → 骨盤を置いていればいつでも)
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(:core のテスト459件、失敗0件。lint は既存の警告5件のみ)
- エミュレータ(AssetDash_API37、`--es demo natural --es select thighL`): 左ももを選んだまま、右上の「人形」の下に「根: 胸」が出る。操作パネルに「根」の行は出ない。押すと「根: 骨盤」になり押した見た目になる(「戻す」も押せるようになる)。そのあと胸を選ぶと、みぞおちの範囲と玉が出る(E16-01)。ボタンはヒントの文と重ならない

## 未検証のまま残したこと
- 実機での位置と押しやすさ
- 骨盤を置いていないときにボタンが出ないことは、テストのみで確かめた(エミュレータでは見ていない)
- カメラのモード・人形のモード中もボタンを出している(操作中の人形の根が切り替わる)。じゃまなら隠す

## ステータス
完了
