# E07-04 保存した体型から既定の体型を選ぶ

親: [E07](../epics/E07-body-type.md)

## 概要
- 保存されている体型の中から、既定(デフォルト)の体型を選べるようにする(2026-11-14、利用者)

## 決まったこと(2026-11-14、利用者)
- 既定の体型は、起動したとき・人形を足したときに使う。「既定の体型に戻す」操作も置く
- 既定を選んでも、今いる人形の体型は変えない。次に足す人形から効く
- 「保存した体型」の一覧の各行に「既定にする」を置き、既定の行に印を付ける。既定を外して固定の値に戻す操作も置く
- 場面を読み込んだときは、場面に保存された体型のまま(既定で上書きしない)

## 進め方
既定の覚え方と人形を足すときの体型は `:core` でテスト先行。画面は手動確認

## 完了条件
- 既定の体型のテストが通る(読めないときは結果型で失敗を返す)
- エミュレータで、既定にした体型が起動・人形の追加・「既定の体型に戻す」で使われる

## 依存
E07-03

## 設計の決定
- `DefaultBody`(`:core` の pose): 既定にした体型の id を、体型とは別の置き場所に1件(`default-body`)で覚える。選んでいなければ固定の値 `BodyParams()`。既定の体型を消したら既定も外す(`forget`)。既定の id はあるのに体型を読めないときはエラーを返し、画面は固定の値で続ける
- 置き場所は `files/settings/default-body.setting`(`FilePoseStore` を拡張子 `.setting` で使う)
- `EditorState.addDoll(body)`: 足す人形の体型を受け取る。画面からは既定の体型を渡す
- 起動したときは、始めの状態に既定の体型を入れる(`rememberSaveable` の初めの値。画面の作り直しのあとは保存した状態に戻るので入れ直さない)
- 一覧のダイアログ: 体型の一覧だけ、ボタン3つ(読み込む・既定にする/既定を外す・削除)を名前と日時の下の行に並べ、既定の行は日時の横に「既定」と出す。場面の一覧は今までどおり
- 「体型」の行に「既定の体型に戻す」を足した(操作中の人形の体型だけを差し替え、ポーズは保つ。`loadBody` と同じ)

## 検証結果
- テスト先行: `DefaultBodyTest`(7件)と `DollSceneTest.人形を足すときに体型を渡すと_その体型で置く` を書き、未定義でコンパイルが通らないことを確認してから実装した。既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(:core のテスト402件、うち照合3件は停止、失敗0件。lint は既存の警告5件のみ)
- エミュレータ(AssetDash_API37、データを消してから):
  - 身長を 72% にして保存 → 一覧で「既定にする」→ 「既定」の印と「既定を外す」に変わり、文言が出る
  - アプリを止めて起動し直すと身長 72% で始まる
  - 身長を 122% にして「既定の体型に戻す」→ 72%
  - 人形1を 122% にして人形を足すと、人形2は 72%、人形1は 122% のまま
  - 「既定を外す」→「既定の体型に戻す」で 100%(固定の値)
  - 既定にした体型を削除すると files/bodies と files/settings が空になり、「既定の体型に戻す」は 100%。警告のログなし、クラッシュなし
  - 最初の一覧のダイアログはボタンを名前の横に3つ並べて窮屈だった(名前が切れ、「既定」の印がボタンに重なった)ので、ボタンを下の行に移して直した
