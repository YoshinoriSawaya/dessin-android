# E16-01 脇腹は骨盤との関節、胸はみぞおちで動かす

親: [E16](../epics/E16-pelvis-root-chain.md)

## 概要
- 骨盤が根のとき、腰(脇腹)を動かすときは、骨盤を動かさずに、脇腹と骨盤の間の関節を動かすのがよい(2026-11-15、利用者)
- いままで(E10-01)は、骨盤が根のときの脇腹の操作は、骨盤と脇腹を止めたまま、みぞおち(胸と脇腹の間)を支点に胸を動かしていた。脇腹と骨盤の間の関節(骨盤の関節)は、骨盤が根のときは動かす手段がなかった(骨盤の操作は全体の操作。E14-04)

## 決まったこと(2026-11-15、利用者)
- 「腰」は脇腹のこと
- 骨盤が根のときの脇腹は、脇腹と骨盤の間の関節を支点に、脇腹と胸を一緒に動かす。骨盤は止まる
- その関節の可動域は骨盤の関節のもの(前 70°・後ろ 35°・左右 35°・ひねり ±45°)
- みぞおちは、骨盤が根のときは胸の操作で曲げる(全体を動かす・回すのは骨盤で行う。E14-04 のまま)

## 進め方
`:core` でテスト先行。操作感は実機で利用者が確かめる

## 完了条件
- 骨盤が根のとき、脇腹の玉・回転オーブ・ひねりで、骨盤が止まったまま骨盤の関節を中心に脇腹と胸が回ることをテストで確かめる
- 骨盤が根のとき、胸の玉・回転オーブ・ひねりで、脇腹と骨盤が止まったままみぞおちから胸が回ることをテストで確かめる
- 胸が根のときの操作は今までどおり(既存のテストが通る)

## 設計の決定
- 骨格に `isReversed(id)`(骨盤が根で骨盤を置いていて、id が胸か脇腹)と `guideJoint(id)`(選んだ部位を動かすときに状態を変える関節。ふつうは部位自身、骨盤から逆にたどる部位は 胸→脇腹・脇腹→骨盤)を足した。E10-01 の `isAnchorSide`(脇腹だけ)はこれに置き換えた
  - 玉・範囲・ドラッグ・2回タップ・回転オーブ・ひねり・向きを戻すは、すべて `guideJoint` の関節の状態を変える。玉は選んだ部位の上向き、範囲は関節の部位(骨盤の側で止まっている)の向きで上下を反転して置く(E10-01 の脇腹の置き方を一般化した)
  - 骨盤が止まる補正(`keepingPelvisOf`)は、骨盤が根で脇腹か骨盤の状態を変えたときに掛ける
- 範囲の形・ピッキング・描画は、選んだ部位ではなく `guideJoint` の関節の可動域で作る(`DollRenderer.drawGuide`・`romPoint`)。範囲を押したときに選ばない部位は、親の代わりに `guideJoint` の部位(骨盤の側の隣)
- 胸(骨盤が根のとき): 緑の範囲を出し、説明は「緑の範囲の中をドラッグ…」。指でのドラッグは全体を動かさず、みぞおちで曲げる。スライダーは傾きの3本を出さず、みぞおちのひねり(符号を逆。E14-04 の脇腹と同じ)を出す。大きさ・身長・乳房・長さは今までどおり
- 脇腹(骨盤が根のとき): ひねりは骨盤の関節のひねり(±45°、符号を逆にして、+ で上半身が胸が根のときの骨盤と同じ向きに回る)。長さは今までどおり
- 向きを戻す: 骨盤が根のときの胸はみぞおち(脇腹の状態)を、脇腹は骨盤の関節(骨盤の状態)を自然な姿勢(E09)に戻す。骨盤の関節の自然な姿勢は、脇腹の前傾 10° を打ち消す向き(骨盤がまっすぐ)
- 「根」の行は今までどおり脇腹を選んでいるときだけ出す

## 検証結果
- テスト先行: `WaistJointTest`(15件。脇腹: 回転オーブ・玉と範囲・ドラッグ・可動域(前70°・後ろ35°)・ひねりの向き・向きを戻す・範囲を押しても骨盤を選ばない。胸: 回転オーブ・玉と範囲・ドラッグ・指でのドラッグ・スライダーとひねりの向き・向きを戻す・説明。骨盤を置いていなければ今まで通り)を書き、未定義でコンパイルが通らないことと、仮の `guideJoint` で14件が失敗することを確認してから実装した(通った1件は骨盤を置いていないときで、今までの動きを確かめるもの)
- 実装後に新しいテストの誤り3件を直した(実装ではなくテストの側)
  - 胸が根のときの比べる側(`chestRoot`)が頭を選んだままだった。胸を選び直した(2件)
  - 脇腹の向きを戻すで、骨盤の関節を「まっすぐ(休止状態)」に戻すと期待していたが、ほかの部位と同じく自然な姿勢に戻る。期待を自然な姿勢にした
  - 範囲と玉の位置を、ひねりの入る回し方で比べていた。ひねりがあると玉は範囲の点からずれる(下の未検証。E10-01 から)。ひねりの入らない回し方にした
- 既存のテストの書き換え(仕様変更のため): `AnchorTest` の「骨盤が根なら脇腹の玉は胸の上向き・範囲は脇腹の向きに上下を反転して置く」。骨盤が根のときのみぞおちの操作は脇腹から胸へ移ったので、同じ確かめを胸(`rib`)で行う形にした。ほかの既存のテストは変えていない(`AnchorTest` の脇腹のドラッグ・回転オーブ、`PelvisRootTest` の脇腹のひねりは、支点が変わっても「上半身が前へ曲がる・同じ向きに回る」が成り立つのでそのまま通る)
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(:core のテスト459件、失敗0件。lint は既存の警告5件のみ)
- エミュレータ(AssetDash_API37、`--es demo natural --es select flank`、根を骨盤にして横から): 脇腹の範囲は骨盤の関節に出て、玉は胸の高さ(骨盤の関節の範囲の半径)。玉を前へ引くと、骨盤と脚はその場のまま骨盤の関節から上半身が前へ倒れる。大きく引くと約70°で止まり、玉は範囲の前の端に来る。「向きを戻す」でまっすぐに戻る。胸を選ぶと、説明が「緑の範囲の中をドラッグ…」、スライダーが大きさ・ひねり・身長・乳房・長さになり、玉はみぞおちの上。玉を前へ引くと、脇腹と骨盤はまっすぐのまま胸だけがみぞおちから前へ曲がる。アプリのクラッシュなし

## 未検証のまま残したこと
- 実機での操作感
- ひねりがあるときは、玉(選んだ部位の上向き)が範囲の上の点(関節の状態の向き)から、ひねりの分だけ回った位置になる。ドラッグした点と玉が少しずれる。E10-01 の脇腹からある性質で、骨盤の関節はひねりが ±45° と大きいので目立つかもしれない
- 骨盤が根のときの胸の回転オーブ・ひねりのスライダーは、エミュレータでは試していない(テストのみ)
- 胸を選んでいるときは「根」の行が出ない(根を戻すには脇腹を選ぶ)→ E16-02 で右上のボタンにし、どの部位でも切り替えられるようにした
- 横から見ると、骨盤の関節の範囲の前側が腕や胸と重なって見えにくい
