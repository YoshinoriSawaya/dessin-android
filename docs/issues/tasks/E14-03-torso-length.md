# E14-03 胸・脇腹・骨盤の長さ

親: [E14](../epics/E14-usage-feedback.md)

## 概要
- 腰の長さを調整できるとよい。胸の長さを身長とは無関係に調整できるとよい(2026-11-14、利用者)

## 決まったこと(2026-11-15、利用者)
- 腰は脇腹と骨盤の両方を、別々に調整できるようにする
- 胸の長さも調整できるようにする

## Claude が決めたこと(利用者に伝えた)
- 体型の項目に胸・脇腹・骨盤の長さ(倍率)を足す。範囲はほかの長さと同じ 70〜130%
- 胸を伸ばすと、首・肩の付け根・脇腹の取り付け位置と乳房の位置も一緒に動く(胸の関節を中心に縦に伸ばす)
- スライダーはその部位を選んだときに出す(胸は胸、脇腹は脇腹、骨盤は骨盤)

## 関連
- E07-02(体型の項目)。首・上腕・前腕・もも・すねの長さと同じ仕組み(部位の形を縦に伸ばし、子の取り付け位置と可動域の表示もそれに従う)

## 進め方
体型の項目・取り付け位置・形の置き方は `:core` でテスト先行。画面は手動確認

## 完了条件
- 長さを変えると子の取り付け位置が縦にだけ動く(横幅・前後は変わらない)ことをテストで確かめる
- 体型の保存・読み込みで新しい項目が残る。古い体型の文字列は 100% で読める
- エミュレータで3本のスライダーが効く

## 設計の決定
- 体型の項目に `chestLength`・`flankLength`・`pelvisLength`(既定 1.0、範囲 0.7〜1.3)を足した。`BodyCodec` にも足し、古い文字列(項目なし)は 100% で読む
- `lengthScale` が胸・脇腹・骨盤にも長さを返す。子の取り付け位置は縦(y)だけを倍率で伸ばすように変えた(胸の子の肩・首の付け根は横や前後にずれているため)。手足の取り付け位置は x・z が 0 なので今までと同じ
- 形の置き方: 胸・脇腹・骨盤の形は縦に伸ばす(骨盤は横幅と掛け合わせる)。乳房と性器は位置だけが動き、形は伸ばさない
- スライダー「長さ」(`TORSO_LENGTH`)を胸・脇腹・骨盤を選んだときの最後に出す
- 胸を伸ばすと胸の関節(みぞおちより上)を中心に上下へ伸びる。首・肩の付け根は上へ、脇腹の付け根は下へ動く

## 検証結果
- テスト先行: `TorsoLengthTest`(10件)を書き、未定義でコンパイルが通らないことを確認してから実装した
- 既存のテストを変えた。理由: スライダーが増える仕様の変更のため
  - `SlidersTest.肋骨は大きさと3つの傾き`・`肋骨の値はオイラー角を度に丸めて出す`: 末尾に胸の長さを足した
  - `SlidersTest.頭は大きさ_肩は肩幅_骨盤は横幅と付け根の内寄り`: 骨盤の一覧の末尾に長さを足した
- `./gradlew lint test assembleDebug` → 成功
- エミュレータ(AssetDash_API37、`--es demo natural`): 胸・脇腹・骨盤の「長さ」をそれぞれ 130% にすると、その部位が縦に伸び、首・腕・脚の付け根が一緒に動く。クラッシュなし
- 実機(Pixel 10a、2026-11-15、利用者): 確認し、問題なし

## 未検証のまま残したこと
- 実機での操作感と、伸ばしたときの見た目(胸の切り口の角度が長さで変わる)
