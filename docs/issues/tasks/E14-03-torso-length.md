# E14-03 胸・脇腹・骨盤の長さ

親: [E14](../epics/E14-usage-feedback.md)

## 概要
- 腰の長さを調整できるとよい。胸の長さを身長とは無関係に調整できるとよい(2026-11-14、利用者)

## 決まったこと(2026-11-15、利用者)
- 腰は脇腹と骨盤の両方を、別々に調整できるようにする
- 胸の長さも調整できるようにする

## Claude が決めたこと(利用者に伝えた)
- 体型の項目に胸・脇腹・骨盤の長さ(倍率)を足す。範囲はほかの長さと同じ 70〜130%
- 胸を伸ばすと、首・肩の付け根・脇腹の取り付け位置と乳房の位置も一緒に動く(胸の関節を中心に縦に伸ばす)
- スライダーはその部位を選んだときに出す(胸は胸、脇腹は脇腹、骨盤は骨盤)

## 関連
- E07-02(体型の項目)。首・上腕・前腕・もも・すねの長さと同じ仕組み(部位の形を縦に伸ばし、子の取り付け位置と可動域の表示もそれに従う)

## 進め方
体型の項目・取り付け位置・形の置き方は `:core` でテスト先行。画面は手動確認

## 完了条件
- 長さを変えると子の取り付け位置が縦にだけ動く(横幅・前後は変わらない)ことをテストで確かめる
- 体型の保存・読み込みで新しい項目が残る。古い体型の文字列は 100% で読める
- エミュレータで3本のスライダーが効く
