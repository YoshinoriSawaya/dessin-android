## 設計の決定
- つま先を部位 `toeL`・`toeR`(表示名「左つま先」「右つま先」)として足した。親は足、関節は足の空間で (0, −0.045, 0.105)(足の前の付け根、足の裏の少し上)
- つま先はヒンジ。φ が正で上(甲の側)へ 60°、負で下へ 30°(`Hinge(π, −30°, 60°)`)。参照軸は足と同じ y、休止方向は前、可動域の表示の半径 0.08
- 足の本体はかかと〜つま先の付け根(z −0.05〜0.105)。かかとは横向きの円柱(半径 0.0225)で丸めた。つま先の箱は z 0.105〜0.15、裏は足の裏と同じ高さで、上は少し低い。足とつま先を合わせた長さは今と同じ 0.20
- 部位チップの最後の段に「左つま先」「右つま先」を足した
- 保存形式は部位の一覧から書くので、つま先の行が自然に加わる。つま先の無い古いデータは、つま先を置いていない扱いになる(版は変えない)

- 既存のテストを変えた。理由: 部位を2つ足す仕様の変更のため

  - `ChestFlankTest.胸と脇腹と骨盤の親子`: 部位の数 21 → 23
  - `EditorStateTest.チップは配置の段ごとに区切る`: つま先の段を足した
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト323件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
