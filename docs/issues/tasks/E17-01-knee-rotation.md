# E17-01 曲げるほど広がるすねのひねり

親: [E17](../epics/E17-knee-structure.md)

## 概要
- すねのひねり(脛骨の回旋)を、曲げ角に応じた範囲で許す。伸ばしたときは 0°、曲げ 90° 以上で外旋 40°・内旋 30°
- 操作はいままでのひねりスライダー。伸ばしているときは範囲が 0 で使えない
- 曲げ角を変えたら、ひねりをその曲げ角の範囲に収める(メモの「θ を変えたときは φ を範囲内に収める」)

## 進め方
`:core` でテスト先行

## 完了条件
- 範囲の計算・スライダー・ドラッグ・回転オーブ・読み込みで、ひねりが曲げ角の範囲に収まることをテストで確かめる

## 検証結果
- テスト先行: `KneeRotationTest`(範囲の計算・左右の鏡像・外旋の向き・スライダー・ドラッグ・回転オーブ・読み込み)を書き、`rollRange` が無くてコンパイルが通らないことを確認してから実装した
- 部位の定義に `rollFullBend`(範囲がいっぱいになる曲げ角)を足し、すねは roll(−40, 30)・90° にした。範囲は `rollRange`、収めるのは `clampRoll`(`aimPart` のヒンジ・`orbRotate`・スライダー・`PoseCodec` の読み込み)
- 既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(:core のテスト487件、失敗0件・止めているもの0件。lint は既存の警告5件のみ)
- エミュレータ(AssetDash_API37): 左すねを 90° 曲げ・ひねり −34° の姿勢で起動し、ひねりのスライダーが −40〜30 の範囲で出ることを見た

- 実機(Pixel 10a)で利用者が確認し、問題なし(2026-11-19)

## 未検証のまま残したこと
- 実機での操作感(伸ばしたときにひねりのスライダーが使えなくなるのが分かりにくくないか)
- 範囲の値(外旋 40°・内旋 30°、90° で最大)はメモの目安のまま
