# E02-07 タッチ操作

親: [E02](../epics/E02-render-ui.md)

## 概要
- 1本指: 選択中の部位を押していれば向きを決める(肋骨なら移動)、それ以外は視点の回転。6px 動くまではドラッグとみなさない
- 2本指: ピンチで距離を変える
- タップで部位を選ぶ。緑の範囲のダブルタップ(420ms 以内・32px 以内)でその点へ向ける
- Web版の pointerdown・pointermove・endPtr の規則を、端末のイベントに依存しない状態機械として `:core` に置く

## 進め方
判定の規則は `:core` でテスト先行、端末のイベントとのつなぎは手動確認

## 完了条件
- 状態機械をJVMテストで確かめ、エミュレータと実機で Web版と同じ手順で操作できる

## 依存
E02-01, E02-04, E02-05, E02-06

## 設計の決定
- 指の操作の規則を、端末のイベントに依存しない `TouchGesture`(`:core` の `editor`)に置いた(テスト先行)。Web版の pointerdown・pointermove・endPtr と同じ: 1本指で選択中の部位を押せば向きを決める(肋骨なら動かす)、それ以外は視点の回転、6dp 動くまでは動かさない、2本指はピンチ、ピンチのあとに残った指では何もしない、タップで選ぶ、緑の範囲を 420ms・32dp 以内に2回タップでその点へ向ける
- 座標は dp で渡す。Web版の CSS px に当たるので、回転の速さ(0.008/0.006 ラジアン毎 dp)や、ドラッグとみなす距離が Web版と同じ感覚になる
- `DollSurfaceView` が指のイベント(MotionEvent)を dp に直して `PointerListener` に渡し、画面が `TouchGesture` を呼んで状態を更新する。onTouchEvent で受け、指を離したときは performClick も呼ぶ(lint の ClickableViewAccessibility を出さないため)

## 検証結果
- テスト先行: `TouchGestureTest`(12件)を書き、コンパイルエラーで失敗することを確認してから実装した
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト220件成功、lint は 0 errors、既存の警告5件のみ)
- エミュレータ(AssetDash_API37、Android 17)で adb の input で操作して確認(Claude):
  - ゴーストの首をタップ → 首が置かれて選択中になる
  - 首の玉をドラッグ → 首が指の方へ傾き、玉が指についてくる(可動域に収まる)
  - 何も無いところをドラッグ → 視点が回る
  - 緑の範囲を2回タップ(間隔 73ms)→ 首がその点へ向く

## 未検証のまま残したこと
- ピンチ(2本指)は adb の input では作れないので、単体テストでだけ確かめた
- 実機での操作感(指の太さ、回転の速さ、ドラッグの追従、ダブルタップの間隔)は E02-12 で利用者が確かめる
- 押したときの当たり判定は UI のスレッドで行う。エミュレータでは遅れは感じなかったが、実機での速さは未確認
