# E19-01 プリセットのポーズ

親: [E19](../epics/E19-preset-poses.md)

## 概要
- ポーズは、胸をまっすぐ前へ向けたときの各部位のワールドの向き(と胸の前傾)で定義し、自然な姿勢(E09)と同じく親から順に置いて向ける(`aim`)
- 肘・ひざを狙いどおりに曲げるため、上腕・もものひねりは、子(前腕・すね)の向きが狙いに最も近くなる値を探して決める
- 当てたあとは、いちばん低い点が床(y = 0)に付くよう高さを合わせる。床の上での向き(胸のワールドの向きのうち鉛直軸まわり)・横の位置・大きさは保つ
- 画面は「保存」の行に「プリセット」を足し、一覧のダイアログから選ぶ

## 進め方
ポーズの定義と当て方は `:core` でテスト先行。見た目はエミュレータと実機で確かめる

## 完了条件
- 各ポーズで、定義した向きに各部位がおおむね向くこと(可動域に収まっていること)、体型・位置・向き・棒・手の形が保たれること、床に付くことをテストで確かめる

## 検証結果
- テスト先行: `PresetPoseTest`(9つの並び・狙いの向きに 15° 以内で向く・棒以外の全部位を置く・狙いの意味・体型や位置や向きや棒や手の形を保つ・床に付く・ほかの人形を変えない)を書き、`PresetPose` が無くてコンパイルが通らないことを確認してから実装した
- 実装の途中で「狙いの向き」の1件が落ちた。立ち姿勢でもすねを数度寄せるためにももを大きくひねる解が選ばれ、足が横を向いていた(ひねりの重みを 0.1 にした)。しゃがむ・体育座り・あぐらは、もも(前 120°・外 70°)の可動域を超える狙いを置いていたので、狙いと胸の前傾を届く値に直した(テストは変えていない)
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(:core のテスト498件、失敗0件。lint は既存の警告5件のみ)
- エミュレータでの見た目は未確認(メモリ不足で止められたあと起動していない)
- 実機(Pixel 10a)で利用者が9つのポーズを当てて確認し、問題なし(2026-11-19)

## 未検証のまま残したこと
- 狙いの向きは Claude が数値で決めた(実機で問題なしとされた)。ポーズを足すときも、テストは可動域に収まることまでしか確かめられない
