# E02-08 スライダー

親: [E02](../epics/E02-render-ui.md)

## 概要
- 肋骨: 大きさ(30〜160%)・前後の傾き・ひねり・横の傾き(オイラー角 YXZ)
- 各部位: ひねり(ロールの範囲。範囲が0なら無効)
- 頭の大きさ、肩幅(左右)、骨盤の横幅、付け根の内寄り(mm)
- ドラッグや回転オーブで値が変わったらスライダーにも反映する(Web版の syncUI)

## 進め方
`:app`(手動確認)

## 完了条件
- エミュレータで各スライダーが効き、他の操作のあとに値が追従する

## 依存
E02-06

## 設計の決定
- 出すスライダー(種類・ラベル・範囲・いまの値・単位)と、値の反映を `:core` の `Sliders.kt` に置いた(Web版の syncUI・onSlider。テスト先行)。値は整数(%・°・mm)で、度は四捨五入
- 肋骨の傾きは、いまの回転をオイラー角(YXZ)に分けて1軸だけ差し替える。スライダーの値もいまの回転から毎回求めるので、ドラッグや回転オーブのあとも値が追従する
- Compose の Material3 Slider を使い、溝を細く(4dp)、つまみとの隙間と終点の印をなくして Web版の range に近づけた。この指定は Material3 で実験的な API なので、その関数に限って OptIn した(変わったら標準の見た目に戻せばよい)
- 範囲が0のスライダー(肩・手・付け根・すね・足のひねり)は使えない表示にする

## 検証結果
- テスト先行: `SlidersTest`(9件)を書き、コンパイルエラーで失敗することを確認してから実装した
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト229件成功、lint は 0 errors、既存の警告5件のみ)
- エミュレータ(AssetDash_API37、Android 17)で adb の input で操作して確認(Claude):
  - 肋骨: 大きさ・前後の傾き・ひねり・横の傾きの4本。前後の傾きを 55°、大きさを 110% にすると、肋骨が前に傾いて大きくなる
  - 骨盤: ひねり(±45°)・骨盤の横幅・付け根の内寄り(41mm)の3本に切り替わる。全部位を置いて横幅を 130% にすると、骨盤が広がって両脚の付け根が外へ動く
- 確認の途中で直したこと: Material3 の標準のスライダーは溝が太く重たく見えたので細くした。「付け根の内寄り」のラベルが切れていたので、ラベルの幅を広げた

## 未検証のまま残したこと
- 肋骨の前後の傾きが ±90° のとき、オイラー角の分け方の都合でひねりと横の傾きの値が入れ替わったように見えることがある(Web版は Euler を別に持つので起きない。回転そのものは同じ)
