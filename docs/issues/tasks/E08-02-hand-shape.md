# E08-02 手の形(グーとパー、親指側)

親: [E08](../epics/E08-body-shapes.md)

## 概要
- 手に指を付け、グーとパーを表現する。パーは扇状、グーはブロックの形。指の関節は作らず、手の形ごと差し替える(2026-11-14、利用者)
- 手の親指側がわかるようにする。グーとパーのどちらの形にも親指側の印を入れる

## 決まったこと(2026-11-14、利用者)
- 手を選んでいるときにボタンで切り替える
- 手の形はポーズの一部として保存する(体型ではない)
- 左右の手は別々に切り替えられる

- 親指側は親指の形で示す(色は変えない)

## 進め方
形状とポーズの保存形式(`:core`)はテスト先行。ボタンと見た目は手動確認

## 完了条件
- 形状・保存形式のテストが通る(古いデータは今の手の形で読み込める)
- 実機で左右別々に切り替えられ、保存・読み込みで手の形が戻る
