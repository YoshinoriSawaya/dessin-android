# E08-02 手の形(グーとパー、親指側)

親: [E08](../epics/E08-body-shapes.md)

## 概要
- 手に指を付け、グーとパーを表現する。パーは扇状、グーはブロックの形。指の関節は作らず、手の形ごと差し替える(2026-11-14、利用者)
- 手の親指側がわかるようにする。グーとパーのどちらの形にも親指側の印を入れる

## 決まったこと(2026-11-14、利用者)
- 手を選んでいるときにボタンで切り替える
- 手の形はポーズの一部として保存する(体型ではない)
- 左右の手は別々に切り替えられる

- 親指側は親指の形で示す(色は変えない)

## 進め方
形状とポーズの保存形式(`:core`)はテスト先行。ボタンと見た目は手動確認

## 完了条件
- 形状・保存形式のテストが通る(古いデータは今の手の形で読み込める)
- 実機で左右別々に切り替えられ、保存・読み込みで手の形が戻る

## 依存
なし

## 設計の決定
- 手の形 `HandShape`(OPEN=パー・FIST=グー、既定はパー)を骨格に左右別々に持つ(`Skeleton.hands`。既定と違う手だけを持つ)。手を外すとパーに戻る
- ポーズの保存(版3)に `hand <handL|handR> <open|fist>` の行を足した。版3は未リリースなので版は上げていない。知らない形はエラー
- 手のメッシュは、パーの手のひら・パーの指と親指・グー(ブロックと親指)を持ち、`PartMesh.handShape` で今の形のものだけを描く(描画・ピッキング・全体を表示はすべて `drawPlan` か同じ判定に従う)
- 親指は前(+z)に付け、手のひらは体側を向く(自然に立ったときの向き)。左右は鏡像。パーの指は手のひらの下端から扇状に開く(端で 10°)、親指は前下へ 45°
- 画面: 手を選んでいるときだけ「手の形」の行(パー・グー)を出す

## 検証結果
- テストは先に書いた(`HandShapeTest`: 既定・左右別々・外すと戻る・形ごとのメッシュ・長さと幅・親指は前・鏡像・保存・画面の選択)。ただし実装の前に失敗することを確認する手順を飛ばした(未定義の型を使うので通らないのは明らかだったが、確認はしていない)
- 既存のテストを1か所変えた。理由: 手は今の形のメッシュだけを描く仕様の変更のため
  - `DrawPlanTest.全部置くと全メッシュを描く`: 数える対象を「今の手の形のメッシュ」にした
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト317件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37): 右手を選ぶと「手の形」の行が出る。グーにすると右手だけがブロックに変わり、左手はパー(扇状の指)のまま。クラッシュなし

## 未検証のまま残したこと
- 実機での見た目(指の開き方、親指の位置と大きさ)。エミュレータでは手が小さく、親指の向きは拡大しても細部まで確かめにくい
- グーのブロックに指の段差(握った指の形)は無い
