# E08-04 乳房・性器の目印

親: [E08](../epics/E08-body-shapes.md)

## 概要
- 乳房と性器の位置の目印を付ける(2026-11-14、利用者)

## 決まったこと(2026-11-14、利用者)
- 印ではなく、体の形として付ける

- 乳房は大きさを体型の項目にする(0% で平ら)。胸を選ぶとスライダー
- 性器は体型に「性別」(男・女)を足して形を切り替える。骨盤を選ぶと切り替え

## 進め方
形状の生成(`:core`)はテスト先行。見た目は実機で確認

## 完了条件
- 形状のテストが通り、実機で見た目を確かめる

## 依存
なし

## 設計の決定
- 体型に `breastSize`(0〜1、既定 0)と `sex`(男・女、既定 男)を足した。既定は v1 の見た目に近いものにした(Claude の仮定。利用者に伝えた)。体型の文字列では性別を 0/1 の数で書く
- 乳房: 胸の前面(y = 0.055、横 ±0.06)を中心に、半径 0.055 の球を大きさで拡大して置く(前後は 0.95 倍)。乳頭は線の色の小さな球。大きさ 0 なら描かない
- 性器: 骨盤の前の下の中央。男は小さな膨らみ(球を縦長・前後に平たく)、女は下向きの三角の薄い面。今の性別の形だけを描く
- どのメッシュを描くかの判定を `PartVisuals.isShown` にまとめた(手の形・乳房・性別)。描画・ピッキング・全体を表示はこれに従う
- 画面: 胸に「乳房」のスライダー、骨盤を選んでいるときに「性別」の行(男・女)

## 検証結果
- テスト先行: `LandmarkTest`(既定・大きさ0なら描かない・左右対称で前に出る・大きいほど前に出る・性別の形だけを骨盤の前下に・スライダー・性別の選択・体型の文字列)を書き、未定義でコンパイルが通らないことを確認してから実装した
- 既存のテストを変えた。理由: 胸に乳房のスライダーとメッシュを足す仕様の変更のため
  - `SlidersTest.肋骨は大きさと3つの傾き`・`肋骨の値はオイラー角を度に丸めて出す`: 末尾に乳房を足した
  - `PartVisualsTest.体型で置き方が変わるのは肩と骨盤と付け根`: 「胸に2つ目のメッシュが無い」を「胸に関節の玉が無い」にした(確かめたい中身はこちら)
  - `DrawPlanTest.全部置くと全メッシュを描く`: 数える対象を `isShown` に合わせた
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト330件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37): 乳房を約70%にすると胸に左右の膨らみと乳頭が出る。骨盤を選ぶと「性別」の行が出て、男は膨らみ、女は下向きの三角に切り替わる。クラッシュなし

## 未検証のまま残したこと
- 実機での見た目(乳房の位置・形、性器の大きさ)
- 乳房は胸の部位の一部なので、胸と一緒に動く(脇腹を曲げても形は変わらない)
