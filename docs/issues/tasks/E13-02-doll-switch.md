# E13-02 人形の追加・削除・切り替え

親: [E13](../epics/E13-multi-doll.md)

## 概要
- 画面から人形を足す・消す・切り替えられるようにする
- どの人形を操作しているかを示す

## 決まったこと
- 「カメラ」のボタンの下に「人形」のボタンを置き、押すとパネルが人形のモード(人形の選択・追加・削除)になる(2026-11-14、利用者)
- 人形のモード中は 3D でタップした人形に切り替える。指の動きはカメラだけを操作するモードと同じ(部位を動かさない)。削除は確認してから(Claude が決めた)
- 操作中でない人形の見た目は操作中と同じ。操作中の人形は選択中の部位の色で分かる(Claude が決めた)

## 進め方
切り替えの規則(`:core`)はテスト先行。画面は手動確認

## 完了条件
- 規則のテストが通り、実機で足す・消す・切り替えができる

## 依存
E13-01

## 設計の決定
- 編集の状態に `dollMode` を持つ(画面の状態には残さない)
- 指の操作(`TouchGesture`): 人形のモード中は部位を拾わず、押したときに `pickDoll` で人形を拾い、タップならその人形に切り替える。ドラッグ・ピンチ・2本指の平行移動はカメラだけを操作するモードと同じ
- パネル: 人形のモード中は、選択中の部位・スライダー・部位チップの代わりに、操作中の人形(人形N・全N体)、「人形」の行(人形1〜N)、「操作」の行(追加は10体未満、削除は2体以上のとき)を出す。表示・保存・体型の行はそのまま
- 追加すると全体を表示し直す。削除は確認のダイアログのあと

## 検証結果
- テスト先行: `DollModeTest`(切り替え・ふだんはほかの人形を触れない・タップで切り替え・ドラッグは視点だけ)を書き、未定義でコンパイルが通らないことを確認してから実装した。既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト386件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37): 「人形」で人形のパネルになる。「追加」2回で3体になり、新しい人形は右に胸だけで並ぶ。3D で1体目をタップすると人形1に切り替わる。「削除」で確認のダイアログが出る。クラッシュなし

## 未検証のまま残したこと

- 削除を実行したときの画面(テストで確かめた。エミュレータではキャンセルした)
