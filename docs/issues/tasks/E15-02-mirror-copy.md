# E15-02 左右対称のコピー

親: [E15](../epics/E15-undo-mirror.md)

## 決まったこと(2026-11-15、利用者)
- 選んだ部位とその先を、反対側へ鏡写しにする(例: 左上腕を選ぶと、左の上腕・前腕・手の向きを右へ)
- 左右のある部位を選んだとき、「向きを戻す」「外す」の並びに「反対側へコピー」を出す

## Claude が決めたこと
- 反対側に置いていない部位は置く(反対側の親が無ければ、親も自然な姿勢で置く)。写す元で置いていない部位は、反対側でも外す
- 手の形(グー・パー)も写す
- コピーは Undo で戻せる(E15-01)

## 進め方
`:core` でテスト先行(写した部位のワールドの位置と向きが、体の中心の面で鏡写しになる)。ボタンは手動確認
