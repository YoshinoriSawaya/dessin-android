# E15-02 左右対称のコピー

親: [E15](../epics/E15-undo-mirror.md)

## 決まったこと(2026-11-15、利用者)
- 選んだ部位とその先を、反対側へ鏡写しにする(例: 左上腕を選ぶと、左の上腕・前腕・手の向きを右へ)
- 左右のある部位を選んだとき、「向きを戻す」「外す」の並びに「反対側へコピー」を出す

## Claude が決めたこと
- 反対側に置いていない部位は置く(反対側の親が無ければ、親も自然な姿勢で置く)。写す元で置いていない部位は、反対側でも外す
- 手の形(グー・パー)も写す
- コピーは Undo で戻せる(E15-01)

## 進め方
`:core` でテスト先行(写した部位のワールドの位置と向きが、体の中心の面で鏡写しになる)。ボタンは手動確認

## 設計の決定
- `EditorState.mirrorSelected()`(`:core` の editor/MirrorCopy.kt)。右の部位の定義は左の鏡像(休止方向の x を反転、基準の向きは同じ)なので、部位の基準フレームでは向きの x 成分だけが反転する。状態は 振れ角 phi はそのまま、振る向き psi とひねり roll は符号を反転。ヒンジは曲げる向きを反対側の定義のものにする
- 反対側の親が置かれていなければ、根の側から自然な姿勢で置く。選んだ部位より根の側は写さない
- 写す元で置いていない部位は反対側でも外す。手の形も写す。選択は変えない
- 画面: 左右のある部位を選んだとき、部位の行の「向きを戻す」の左にボタンを出す。文字は写す先の側(左の部位なら「右へコピー」、右なら「左へコピー」)。初めは「反対側へコピー」にしたが、「左つま先」などの名前が「左つま…」と切れたため短くした
- 「選択中の部位」の見出しは折り返さないようにした(ボタンが増えて2行に折れていた)
- Undo(E15-01)は画面の状態の書き換えを記録するので、コピーも1段として戻せる

## 検証結果
- テスト先行: `MirrorCopyTest`(7件)を書き、未定義でコンパイルが通らないことを確認してから実装した。腕と脚(ひざの転がりのずれを含む)と、胸を回し動かしたときに、写した部位の関節の位置と回転が胸の空間の x = 0 の面で鏡写しになることを確かめる
- 実装の途中で、手でない部位に手の形を書こうとして例外になった(手の形は手だけが持つ)。手だけに写すよう直した。テストは変えていない
- 既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(:core のテスト444件、失敗0件)
- エミュレータ(AssetDash_API37、`--es demo all --es select upperArmL`、正面): 「右へコピー」で右腕が左腕の鏡写しになり、「戻す」で元に戻る。右の部位では「左へコピー」になる。「左つま先」を選んでも名前が切れない。クラッシュなし
