# E02-04 人形の描画

親: [E02](../epics/E02-render-ui.md)

## 概要
- Skeleton のワールド変換で部位を描く。置いた部位は通常の色、選択中は強調色、置ける部位は半透明の影(ゴースト)、それ以外は描かない(Web版の refresh)
- 正中線・輪郭線、関節の玉、頭の面
- 選択中の部位の可動域(緑)と玉。玉は視点からの距離で大きさを変える(Web版の updateGuide)

## 進め方
`:app`(手動確認)

## 完了条件
- エミュレータで全部位を置いた状態と、ゴースト・選択中・可動域の見た目を Web版と見比べる

## 依存
E02-02, E02-03

## 設計の決定
- 何をどう描くか(置いた部位・選択中・関節の玉・顔の面・ゴースト・描かない、線と輪郭の有無、可動域を出す部位)は `:core` の `drawPlan` で決める(Web版の refresh。テスト先行)。表示の切替は `DisplayOptions`
- 描く順序は Web版(three.js)と同じ: 不透明な部位 → 半透明のゴースト(奥行きを書かず、奥から順に) → 可動域の面・縁・玉の白い縁・玉(奥行きを見ずに手前へ)
- 色・透明度は Web版の材質の値。表側だけを描き、顔の面と可動域だけ両面(Web版の side と同じ)
- 奥行きのバッファは24ビット
- エミュレータで状態を作って確かめるため、デバッグビルドだけ起動時の状態を adb から指定できるようにした(`DebugStart.kt`。手順は docs/development.md)

## 検証結果
- テスト先行(描き方の計画): `DrawPlanTest` を書き、コンパイルエラーで失敗することを確認してから実装した。GL の部分は手動確認
- エミュレータ(AssetDash_API37、Android 17)で、起動時の状態を変えて確認(Claude が adb で確認):
  - 初期状態: 肋骨が選択中の色、首・左右の肩・骨盤がゴースト
  - 全部位を置き左上腕を選択: 全部位が描かれ、選択中の上腕に可動域(緑)と玉(赤に白い縁)が出る。正中線・輪郭・関節の玉も出る
  - 首を選択: 首が選択中の色、頭がゴースト、首の可動域と玉が出る
- 確認の途中で見つけて直した不具合:
  - 半透明のゴーストに縞が出た → 裏側の面も描いていた。表側だけを描くようにした
  - 正中線の管が2本線に見えた → 管の三角形が内向きだった。再現テスト `LinesTest.管の面は外を向く` を先に書いて失敗を確かめてから直した
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト181件成功、lint は 0 errors、既存の警告5件のみ)

## 未検証のまま残したこと

- 選択中の関節の玉と肋骨の上面の境目が多角形の形に見える(形の交わり。Web版も同じ形と配置)
