# E01-03 基準フレーム・方向・可動域

親: [E01](../epics/E01-logic-port.md)

## 概要
基準フレーム Qb(`baseQuat`)、方向 `dirVec(φ,ψ)`、可動域 `phiMax(ψ)` を実装する。

## 完了条件
- 4象限の楕円境界、ヒンジのときは max を返すこと、上限 π のテストが通る

## 依存
E01-01, E01-02

## 設計の決定
- 関数名は Web版に合わせた(`baseQuat`・`dirVec`・`phiMax`)。トップレベル関数として `skeleton/RangeOfMotion.kt` に置いた
- `phiMax` はコーンを受け取る版と、部位(ヒンジならその最大値)を受け取る版の2つ。根(肋骨)を渡すと例外
- `baseQuat` は休止方向と参照軸が平行だとフレームが決まらない。全部位で平行にならないことをテストで確かめた

## 検証結果
- テスト先行: `RangeOfMotionTest` を書き、コンパイルエラーで失敗することを確認してから実装した
- `./gradlew :core:test` → `RangeOfMotionTest` 14件を含め、全43件が成功
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(lint は 0 errors、既存の警告5件のみ)
