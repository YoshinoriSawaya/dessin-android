# E15-01 Undo と Redo

親: [E15](../epics/E15-undo-mirror.md)

## 決まったこと(2026-11-15、利用者)
- 戻せるのは人形の変更すべて: ポーズ(向き・位置・部位の追加と外し)、体型、人形の追加・削除、場面・体型の読み込み
- 視点・表示の切り替え・部位の選択・モードは戻さない
- 「戻す」「やり直す」のボタンを 3D の右上(「カメラ」「人形」の下)に置く

## Claude が決めたこと
- 1回のドラッグ・スライダーの1回の操作・回転オーブの1回のドラッグを1段にまとめる
- 履歴は 100 段まで。画面の作り直し(回転など)やアプリを閉じると履歴は消える

## 進め方
履歴の持ち方と、戻したときの状態は `:core` でテスト先行。ボタンと操作のまとめ方は手動確認
