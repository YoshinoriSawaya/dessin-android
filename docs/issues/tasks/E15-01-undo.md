# E15-01 Undo と Redo

親: [E15](../epics/E15-undo-mirror.md)

## 決まったこと(2026-11-15、利用者)
- 戻せるのは人形の変更すべて: ポーズ(向き・位置・部位の追加と外し)、体型、人形の追加・削除、場面・体型の読み込み
- 視点・表示の切り替え・部位の選択・モードは戻さない
- 「戻す」「やり直す」のボタンを 3D の右上(「カメラ」「人形」の下)に置く

## Claude が決めたこと
- 1回のドラッグ・スライダーの1回の操作・回転オーブの1回のドラッグを1段にまとめる
- 履歴は 100 段まで。画面の作り直し(回転など)やアプリを閉じると履歴は消える

## 進め方
履歴の持ち方と、戻したときの状態は `:core` でテスト先行。ボタンと操作のまとめ方は手動確認

## 設計の決定
- `:core` の `UndoHistory`(不変)。戻す単位は `SceneSnapshot`(場面の全員と操作中の人形の番号)。`change(before, after)` は人形が変わったときだけ1段を積み、`begin`・`commit` の間はまとめて1段にする。100段を超えたら古いものから捨てる。新しく変えるとやり直しは消える
- 戻すと人形の状態だけが差し替わり、視点・表示・モードは今のまま。選んでいた部位が戻した人形に無ければ胸を選ぶ
- 操作の途中(begin のあと)で戻すと、その操作を確定してから戻す
- 画面(`DessinScreen`)は、状態を書き換えるたびに `change` を呼ぶ委譲(`Recorded`)を通す。視点や表示の変更は人形が変わらないので記録されない。3D の指の操作は押してから離すまで、スライダーは `onValueChangeFinished` まで、回転オーブは指を離すまでを1段にする
- 「戻す」「やり直す」は 3D の右上(「カメラ」「人形」の下)。押せないときは淡い文字(`ToolChip` に enabled を足した)

## 検証結果
- テスト先行: `UndoHistoryTest`(11件)を書き、未定義でコンパイルが通らないことを確認してから実装した。既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL
- エミュレータ(AssetDash_API37): 首を置き、ひねりのスライダーをドラッグ(0° → 15°)→「戻す」1回で 0° に戻る(ドラッグが1段)→ もう1回で首が外れ胸が選ばれる。戻せないとき「戻す」は淡くなる →「やり直す」2回で首と 15° が戻る。クラッシュなし

- 実機での操作感(ボタンの位置、3D のドラッグ・2本指の操作のまとまり方)
- 履歴は画面の作り直し(回転など)で消える
