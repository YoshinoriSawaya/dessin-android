# E02-10 表示の切替と視点のボタン

親: [E02](../epics/E02-render-ui.md)

## 概要
- 全体を表示、正面・横・背面・上
- ガイド(可動域・ゴースト・凡例)、正中線、関節の玉、格子の切替
- 最初に表示するヒントと凡例。最初に触ったらヒントを消す

## 進め方
`:app`(手動確認)

## 完了条件
- エミュレータで各ボタンと切替が Web版と同じように効く

## 依存
E02-04, E02-06

## 設計の決定
- 表示の切替(ガイド・正中線・関節の玉・格子)、視点のプリセット、全体を表示を `:core` の `editor/ViewControls.kt` に置いた(テスト先行)。全体を表示は E02-02 の `fitBounds` と E02-01 の `OrbitCamera.fit` を使い、向きは変えない。起動時の全体を表示も同じ関数にまとめた
- 「表示」の段のチップは Web版と同じ並び(全体を表示・正面・横・背面・上・ガイド・正中線・関節の玉・格子)。入/切のチップは入のとき塗る(Web版の aria-pressed)
- ヒントは 3D に最初に触れたら消す。画面の高さが 620dp 以下なら最初から出さない(Web版の max-height:620px)。ヒントを出すかは画面だけの状態として rememberSaveable で持つ(保存形式には入れない)
- 凡例(可動域・ドラッグする点・次に置ける部位)は 3D の左下に重ね、ガイドを消すと一緒に消す
- 画面の高さは lint の勧めに従い LocalWindowInfo から求める(Configuration.screenHeightDp は対象 SDK によって扱いが違う)

## 検証結果
- テスト先行: `ViewControlsTest`(5件)を書き、コンパイルエラーで失敗することを確認してから実装した
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト242件成功、lint は 0 errors、既存の警告5件のみ)
- エミュレータ(AssetDash_API37、Android 17)で adb の input で操作して確認(Claude):
  - 起動: ヒント(上)と凡例(左下)が出る。「表示」の段のチップが並び、4つの切替は入(塗り)
  - 3D をタップするとヒントが消える
  - 4つの切替を切にすると、可動域・玉・凡例・正中線・関節の玉・格子が消え、人形だけになる
  - 肋骨を選んで画面の右上へドラッグしてから「全体を表示」を押すと、人形が画面の中央に戻る

## 未検証のまま残したこと
- 画面の高さが 620dp 以下の端末でヒントが出ないこと(エミュレータは高い画面のみ)
