# E18-01 手に持たせる棒

親: [E18](../epics/E18-stick.md)

## 概要
- 部位「棒」(stickL・stickR)を手の子に足す。取り付けは拳の中(握りの中心)、休止方向は前(+z)、可動域は ±45°・ひねり ±90°
- 形は細長い板状の直方体(幅 0.03・厚さ 0.012)。幅の向きは手の長さの向き、片方の広い面に線を引いて面の向きが分かるようにする
- 長さ(既定 0.6)と握る位置(0% で後ろの端、50% で真ん中、100% で前の端。既定 50%)はポーズの一部として人形ごとに持ち、保存する(ポーズの形式は版4)
- 棒を置いたら手をグーにする

## 進め方
`:core` でテスト先行。見た目と操作感はエミュレータと実機で確かめる

## 完了条件
- 部位の定義・置き方・見た目の置き方・スライダー・自動のグー・保存と読み込み・左右のコピーをテストで確かめる
