# E01-05 方向から状態への変換

親: [E01](../epics/E01-logic-port.md)

## 概要
`aimPart`: ワールドでの方向を状態に変換し、コーンまたはヒンジの範囲にクランプする。

## 完了条件
- 範囲外の方向が境界に収まる
- φ≈0 のとき ψ を保つ
- ヒンジの min・max が効く

## 依存
E01-04

## 設計の決定
- `aimPart(spec, current, dirInParent)` は親の空間での方向を受け取り、新しい状態を返す純粋関数にした。ワールドの方向から親の空間への変換(Web版の `pq.invert()`)は、親のワールド回転を持つ E01-08 で行う
- 方向は関数の中で正規化する(Web版は呼び出し側で正規化している)

## 検証結果
- テスト先行: `AimTest` を書き、コンパイルエラーで失敗することを確認してから実装した
- `./gradlew :core:test` → `AimTest` 9件を含め、全62件が成功
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(lint は 0 errors、既存の警告5件のみ)

## 未検証のまま残したこと
- 休止方向のちょうど反対へ向けたとき、psi は atan2(0, −0) = π になる(Web版と同じ式なので同じ挙動のはずだが、テストはしていない)
- Web版の出力との数値の照合は E01-10 で行う

## ステータス
完了
