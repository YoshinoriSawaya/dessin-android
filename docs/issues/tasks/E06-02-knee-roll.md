# E06-02 ひざの転がり

親: [E06](../epics/E06-limb-tuning.md)

## 概要
- ひざは単一の軸ではなく、大腿骨の面を少し転がるように曲がる。それを反映する
- 近似: すねの回転の中心を、ひざの関節から 0.03 上(大腿骨の顆の中心)に置く。曲げるにつれてすねの付け根が丸みに沿って後ろ上へ移る(90° で後ろ 0.03・上 0.03)
- 部位の定義に「回転の中心のずれ(pivot)」を足し、ワールド変換・玉の位置・可動域の表示がそれに従う
