# E12-01 カメラだけを操作するモード

親: [E12](../epics/E12-camera-mode.md)

## 概要
- カメラだけを操作するモードを足す(2026-11-14、利用者)
- いまは1本指のドラッグで、部位に触れれば部位を動かし、何も無いところなら視点を回す。人形の上から視点を回そうとすると部位が動いてしまう

## 決まったこと(2026-11-14、利用者)
- モード中は、1本指で視点を回す・ピンチで拡大縮小・2本指のドラッグで平行移動(注視点を動かす)。タップしても部位を選ばない
- 切り替えは、3D の画面の右上に重ねた「カメラ」のボタン

## 進め方
指の操作の判定(`:core` の TouchGesture)はテスト先行。画面は手動確認

## 完了条件
- モード中は部位が動かず視点だけが動くテストが通る
- 実機で切り替えて操作できる

## 依存
なし

## 設計の決定
- 編集の状態に `cameraOnly` を持ち、画面の状態(`EditorStateCodec` の `cameraonly` の行)に残す。行の無い古い状態はオフ
- 指の操作(`TouchGesture`): モード中は押したときに部位を拾わない(1本指はいつも視点の回転、タップでは何も選ばない)。2本指はピンチに加えて、2本の指の真ん中の動きで平行移動する(モードでないときの2本指は今までどおりピンチだけ)
- 平行移動(`OrbitCamera.pan`)は、注視点の奥行きで指の動きに合わせて注視点を逆へ動かす(注視点の奥行きの物が指についてくる)
- 画面: 3D の画面の右上に「カメラ」のボタン(押している間は黒)。ヒントの文字は右に余白を取り、ボタンと重ならない

## 検証結果
- テスト先行: `CameraModeTest`(既定とモードの保存・ふつうは部位が動く・モード中は視点だけが回る・タップで選ばない・2本指で平行移動して距離は変わらない・ピンチ・平行移動の量)を書き、未定義でコンパイルが通らないことを確認してから実装した。既存のテストは変えていない(指の操作の既存のテストもそのまま通る)
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト363件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37): 右上に「カメラ」のボタンが出て、ヒントと重ならない。押すと黒くなり、首の玉の上をドラッグしても首は動かず視点が回る。体をタップしても選択は変わらない。クラッシュなし

## 未検証のまま残したこと
- 2本指の平行移動は、adb では2本の指を同時に動かせないためエミュレータで試していない(テストで確かめた)。実機で確かめる
- 実機での操作感(ボタンの位置と大きさ、平行移動とピンチが同時に効くことの使い心地)
