# E13-05 操作中の人形を見分けやすくする

親: [E13](../epics/E13-multi-doll.md)

## 概要
- 複数の人形のとき、操作中の人形は選択中の部位の色でしか見分けられなかった。v1.2.0 の「次のフェーズの候補」から進める(2026-11-15、利用者)

## 決まったこと(2026-11-15、利用者)
- 人形のモード中だけ、操作中でない人形を淡く描く
- 「表示」の行に切り替え「ほかを淡く」を足す。既定はオンで、オフにすると人形のモード中も淡くしない

## Claude が決めたこと
- 淡くするのは色だけで、不透明のまま(重なり・影・タップでの切り替えは今までどおり)。面の色は元の色を 35% 残して紙の色に寄せ、陰影も同じ割合で弱める。輪郭線と正中線も同じ割合で紙の色に寄せる
- 切り替えは画面の状態(`options` の6番目)に残す。古い状態はオン

## 進め方
判断(いつ淡くするか・描き方の印)は `:core` でテスト先行。色は GL の描画なので手動確認

## 設計の決定
- `DisplayOptions.fadeOthers`(既定 true)と `Display.FADE_OTHERS`。淡くするかは `EditorState.fadeOthers`(= 人形のモード中 かつ 切り替えがオン)
- `MeshDraw.faded` を足し、`otherDollPlan(skeleton, options, faded)` が操作中でない人形のメッシュに付ける。操作中の人形には付かない
- 描画(`DollRenderer`)は faded のメッシュを、色 × 0.35 + 紙の色 × 0.65(陰影は色の側だけに掛かる)で描き、輪郭線・正中線は紙の色に寄せた色で描く

## 検証結果
- テスト先行: `FadeOthersTest`(4件)を書き、未定義でコンパイルが通らないことを確認してから実装した
- 既存のテストを1つ変えた: `ShadowTest.影の項目が無い古い画面の状態も読める` は、画面の状態の `options` から5番目だけを消して「影が無かったころの形」を作っていた。6番目(ほかを淡く)が増えたので、5番目以降を消すようにした。確かめていること(影の無い古い状態は影あり)は変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL
- エミュレータ(AssetDash_API37、`--es demo multi` の3体): ふだんは3体とも同じ見た目、人形のモードにすると操作中でない2体が淡くなる、「ほかを淡く」をオフにすると人形のモードでも淡くならない

- 実機(Pixel 10a、2026-11-15、利用者): 人形のモードでほかが淡くなること、淡さ(35%)、「ほかを淡く」のオフを確認し、問題なし
