# E06-01 もものひねりと手首

親: [E06](../epics/E06-limb-tuning.md)

## 概要
- もものひねりの範囲を ±45° から ±90° にする
- 手は休止状態で平たい面が体側を向くようにする(手の箱を縦軸まわりに 90° 回す)
- ひねり(回内・回外)は前腕で行う: 前腕のひねりを ±80° から ±90° にし、手はひねらない(利用者の指摘: 手をひねるのではなく前腕をひねる)
- 手首の曲がる向きを面に合わせる: 手の平・甲の側(±x)に 60°、親指・小指の側(前後)に 25°(もとは前後 60°・横 25°)
