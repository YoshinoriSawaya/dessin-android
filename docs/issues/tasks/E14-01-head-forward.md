# E14-01 頭を首に対して前へずらす

親: [E14](../epics/E14-usage-feedback.md)

## 概要
- 頭が後ろ側過ぎるように感じる(2026-11-14、利用者)

## 決まったこと(2026-11-15、利用者)
- 首の付け根は背骨の線のまま。頭の球(と顔の面)を首の上で前へずらす(頭蓋は首の真上より前へ張り出すため)

## 関連
- E04-03 で首の付け根を背骨の線(前後 −0.035)へ移した。E07-01 で頭を 70% に、E09 で首を前へ 15° 傾けた

## 進め方
頭の形の置き方を `:core` でテスト先行。見た目はエミュレータで横から確かめる

## 完了条件
- 頭の形の中心が首の軸より前にあることをテストで確かめる
- エミュレータで横から見て、頭が首の上で前に出ている

## 設計の決定
- 頭の球と顔の面を、頭の関節の空間で前へ 0.025 ずらした(`PartVisuals.HEAD_FORWARD`)。頭の大きさ 100%(v1 の 70%)のとき、ワールドで約 17mm
- 頭の関節(首の上端)の位置・回転の中心・可動域の表示は変えない。見た目の形だけを動かす

## 検証結果
- テスト先行: `PartVisualsTest.頭の球と顔の面は首の軸より前に置く` を書き、失敗を確認してから実装した。既存のテストは変えていない
- `./gradlew :core:test` → 成功
- エミュレータ(AssetDash_API37、`--es demo natural --es select head`、横): 頭の球が首の上で前に出て、首が頭の後ろ寄りに入る
- 実機(Pixel 10a、2026-11-15、利用者): 確認し、問題なし

## 未検証のまま残したこと
- ずらす量(0.025)が足りるかは実機で利用者が見る

## ステータス
完了
