# E13-03 複数の人形の描画とピッキング

親: [E13](../epics/E13-multi-doll.md)

## 概要
- すべての人形を描く。可動域・玉・半透明の影(置く前の部位)は操作中の人形だけに出す
- タップでほかの人形の部位に触れたときの扱い(その人形に切り替える、など)
- 全体を表示はすべての人形が入るようにする

## 決まったこと
- 人形のモードでないときは、操作中の人形だけを触れる。人形のモード中は、タップした人形に切り替える(E13-02 で使う。Claude が決め、利用者に伝えた)
- 影はすべての人形から落とす(人形どうしにも落ちる。Claude が決めた)

## 進め方
ピッキングと全体を表示(`:core`)はテスト先行。描画は手動確認

## 完了条件
- ピッキングと全体を表示のテストが通り、実機で複数の人形が描かれる

## 依存
E13-01

## 設計の決定
- `otherDollPlan`: 操作中でない人形は、置いた部位だけを選択の色・半透明の影・可動域なしで描く(関節の玉・正中線の切り替えには従う)
- 描画は操作中の人形のあとにほかの人形を同じ材質で描く。影の下描きにはすべての人形を入れ、範囲もすべての人形を囲む(`sunLightMatrix(List)`)
- `pickDoll`: 置いた部位のうち最も手前に当たった人形の番号を返す(人形のモードで使う)。ふだんのピッキングは操作中の人形だけ(今までどおり)
- 全体を表示はすべての人形を囲む(E13-01)
- デバッグ起動に `--es demo multi`(全部位を自然な姿勢で置いた人形を3体)を足した

## 検証結果
- テスト先行: `MultiDollTest`(人形の番号・手前の人形・ほかの人形の描き方・影の範囲)を書き、未定義でコンパイルが通らないことを確認してから実装した。既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト382件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37、`--es demo multi`): 3体が並んで描かれ、操作中の人形だけが選択の色。起動時の全体を表示で3体が入る。クラッシュなし

## 未検証のまま残したこと
- 実機での重さ(人形が増えると描画と影の下描きが増える。10体のとき)
- 操作中でない人形の見た目は操作中と同じ材質(→ E13-05 で、人形のモード中は淡く描くようにした)
