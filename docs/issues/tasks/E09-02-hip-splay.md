# E09-02 太ももの付け根の角度とハの字

親: [E09](../epics/E09-default-posture.md)

## 概要
- 太ももの付け根と太ももが、いまは直角に繋がっているように見える。少し鈍角にする(2026-11-14、利用者)
- 初期姿勢で少しハの字になっているようにする(同上)

## 進め方
`:core` の部位の定義・形状を変えるのでテスト先行。見た目は実機で確認

## 完了条件
- 部位の定義・形状のテストが通り、実機で見た目を確かめる

## 依存
なし

## 決まったこと(2026-11-14、利用者)
- 角度は控えめ: 首は前へ 15°(頭は後ろへ 15° で傾きなし)、脇腹は前へ 10°(骨盤は後ろへ 10° で傾きなし)、付け根は下へ 20°・太ももは外向き 5°(付け根と太ももの角は約 115°)
- 自然な姿勢は、部位を初めて置いたときと「向きを戻す」で入れる。可動域の基準(0°)はまっすぐのまま。保存済みのポーズは変わらない

## 設計の決定(E09-01・E09-02 共通)
- `NaturalPose`(`:core` の editor)に、胸がまっすぐのときの各部位の向きを書き、可動域の計算(aim)で親に対する状態に直す。ほかの部位はまっすぐ
- 画面の操作(`EditorState.select` で初めて置くとき、`resetSelected`)だけがこれを使う。骨格の計算(`Skeleton.place`・休止状態)と保存形式は変えていない
- 脇腹の「前傾」は、首と同じく上の端(胸)が前に出る傾きと解釈した(下へ向かって後ろへ傾き、骨盤は胸より少し後ろになる)。Claude の解釈なので利用者に伝えた
- 付け根を下へ傾けると太ももも一緒に内へ傾くので、太ももは外へ戻して外向き 5° にした
- デバッグ起動に `--es demo natural`(画面で順に選んだときと同じく全部位を自然な姿勢で置く)を足した

## 検証結果(E09-01・E09-02 共通)
- テスト先行: `NaturalPoseTest`(首と頭・脇腹と骨盤・付け根と太もものハの字と角・ほかはまっすぐ・向きを戻す・選び直し・骨格の休止状態はまっすぐ)を書き、3件が失敗するのを確認してから実装した
- 既存のテストを1か所変えた。理由: 向きを戻すと自然な姿勢に戻る仕様の変更のため
  - `EditorStateTest.向きを戻すのは選択中の部位だけ`: 骨盤の期待値を休止状態から自然な姿勢にした
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト337件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37、`--es demo natural`): 正面で脚がハの字に開く。横から見て首が少し前へ傾き頭はまっすぐ、骨盤は胸より少し後ろ。クラッシュなし

## 未検証のまま残したこと
- 実機での見た目(角度の大きさ)。角度は `NaturalPose` の値で調整できる
- 置く前の部位(半透明の影)はまっすぐの姿勢で表示され、置くと自然な姿勢に変わる
- 脇腹の前傾の向きの解釈(逆なら向きの符号を変える)
