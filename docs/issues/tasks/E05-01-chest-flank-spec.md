# E05-01 胸と脇腹の部位の定義

親: [E05](../epics/E05-chest-flank.md)

## 概要
- 肋骨を胸(根、id は rib のまま、表示名「胸」)と脇腹(id flank、表示名「脇腹」)に分ける。高さの比は 6.5:3.5(みぞおちの高さで分ける)
- 脇腹の関節は分かれ目の背骨の線(前後 −0.035)。休止方向は下、可動域は前 25°・後ろ 20°・左右 20°、ひねり ±30°(案)
- 骨盤の親を脇腹にする(骨盤のワールドの位置は休止状態で変わらない)
- 保存形式の版を上げ、古いデータ(骨盤が肋骨の子)は脇腹を休止状態で置いた形で読み込む

## 完了条件

## 設計の決定
- 胸は id `rib` のまま(保存データとの互換のため)、表示名を「胸」にした。脇腹は `flank`
- 脇腹: 関節 (0, 0.15 − 0.195, −0.035)、休止方向は下、長さ 0.105、可動域の表示の半径 0.15、可動域は前 25°・後ろ 20°・左右 20°、ひねり ±30°(利用者の確認待ちの案)
- 骨盤: 親を脇腹にし、取り付け位置を (0, −0.105, 0) にした。休止状態のワールドの位置は分ける前と同じ
- 保存形式を版2にした。版1(脇腹が無い)を読むときは、骨盤が置かれていれば脇腹を休止状態で置く。保存データに行が無い部位は休止状態で置く
