# E11-01 体に落ちる影

親: [E11](../epics/E11-self-shadow.md)

## 概要
- 平行光源のシャドウマップで、部位の影を他の部位に落とす。床には落とさない(2026-11-14、利用者)
- 動作が少し重くなるのは許容する(同上)

## 進め方
`:app` の GL 描画なので手動確認(エミュレータと実機)

## 完了条件
- 実機で腕の影が胸に落ち、操作中にカクつかない

## 依存
なし(E08 のあとが望ましい)

## 設計の決定
- シャドウマップ: 太陽(陰影と同じ向き (2.2, 4.5, 3.2))から見た正射影で、置いた部位(ゴーストを除く)の奥行きを 2048×2048 の深度テクスチャに描く。範囲は置いた部位を囲む箱に合わせる(`:core` の `sunLightMatrix`)
- 陰影のシェーダで、影の中では平行光の分(0.85)を消す。半球光は残すので真っ黒にはならない。3×3 点の比較でふちをぼかし、面の傾きに応じて奥行きをずらして自分の影の縞を避ける。下描きは裏も表も描き、ポリゴンオフセットをかける
- 床には落とさない(床は格子の線だけで、影を受ける面が無い)
- 表示の切り替えに「影」を足した。既定はオン(Claude の仮定。利用者に伝えた)。画面の状態に残し、影の項目が無い古い状態は影ありとして読む
- 下描き先を作れない端末では、理由をログに残して影なしで描く

## 検証結果
- `:core` はテスト先行: `ShadowTest`(太陽の向き・置いた部位がすべて範囲に入る・太陽に近いほど奥行きが小さい・何も置かなければ無し・切り替えと画面の状態・古い状態)を書き、未定義でコンパイルが通らないことを確認してから実装した。既存のテストは変えていない
- `:app` の GL 描画は手動確認(CLAUDE.md の方針)
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト356件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37、`--es demo all`): シェーダのエラーのログ無し、クラッシュ無し。影あり・なしの画面の差を取ると、首(頭の影)、胸の右側から脇腹・骨盤(腕の影)、太ももの付け根、ひざのまわりが暗くなっている。自分の影の縞は見えない

## 未検証のまま残したこと
- 実機での重さ(操作中にカクつかないか)。エミュレータは実機の GPU と違うので測っていない
- 実機での影の濃さ・ふちのぼけ具合(濃さは平行光を消す割合、ぼけは比べる点の数で調整できる)
- 人形がとても小さい・大きいときの影の細かさ(範囲を箱に合わせるので、大きさによらずほぼ同じ細かさのはず)
