# E02-01 カメラと画面からのレイ

親: [E02](../epics/E02-render-ui.md)

## 概要
- 軌道カメラ(注視点・yaw・pitch・距離)から、視点の位置と向き、ビュー行列・投影行列(視野35度)を求める。行列型 Mat4 を数学型に足す
- 画面の点から3Dのレイを作る(Web版の setRay)。肋骨のドラッグ移動用に、画面上の移動量をワールドの移動量に直す(screenDelta)
- 回転の量と範囲(yaw は 0.008/px、pitch は 0.006/px で −1.2〜1.4)、ピンチ・ホイールの距離の範囲(0.8〜9)
- 視点のプリセット(正面・横・背面・上)と、置いた部位全体が入る「全体を表示」(fitView)。全体を表示は部位の大きさが要るので、境界の計算は E02-02 の寸法を使う

## 完了条件
