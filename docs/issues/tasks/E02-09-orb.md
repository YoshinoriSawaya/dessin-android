# E02-09 回転オーブ

親: [E02](../epics/E02-render-ui.md)

## 概要
- 中央のドラッグで傾け、外周(半径の78%より外)のドラッグで視線まわりにひねる。回転軸はカメラの向きから決める(Web版の orb の pointermove)
- 選択中の部位の向きを、3つの輪と「前」「上」の印で描く(Web版の drawOrb)

## 進め方
ドラッグから回転への変換は `:core` でテスト先行、描画は手動確認

## 完了条件
- ドラッグ量から回転への変換をJVMテストで確かめ、エミュレータで部位と肋骨を回せる

## 依存
E02-01, E02-06

## 設計の決定
- ドラッグから回転への変換(`OrbGesture`)と、向きの表示の計算(`orbProject`・`orbPicture`)を `:core` の `editor/Orb.kt` に置いた(テスト先行)。Web版と同じ: 88dp の円、球の半径 37dp、半径の 78% より内側で押すと視点の縦軸・横軸まわりに傾け(π/(2×37) ラジアン毎 dp)、外側で押すと中心のまわりの角度の変化だけ視線まわりにひねる(±π の境目をまたいでも小さい角度)
- 回転は `EditorState.applyOrb` で選択中の部位に加える(E01-07 の `Skeleton.orb`。肋骨はそのまま掛かる)
- 描画は Compose の Canvas(`OrbView`): 点線の外枠、放射グラデーションの球、3つの輪(手前は濃く太く、奥は薄く細く)、「前」「上」の印。スライダーの右に置く(Web版の .ctl)

## 検証結果
- テスト先行: `OrbGestureTest`(8件)を書き、コンパイルエラーで失敗することを確認してから実装した
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト237件成功、lint は 0 errors、既存の警告5件のみ)
- エミュレータ(AssetDash_API37、Android 17)で adb の input で操作して確認(Claude):
  - 全部位を置いて左上腕を選ぶと、オーブに輪と「前」「上」の印が出る
  - 中央をドラッグ → 上腕の向きが変わり、ひねりのスライダーも追従(51°)、オーブの輪も回る
  - 外周を円に沿ってドラッグ → 上腕が回る

## 未検証のまま残したこと
- Web版のオーブの球のグラデーションは2つの円の間のもの(createRadialGradient)で、Compose では1つの円のグラデーションで近似した。見た目の差は小さい
- 実機での操作感(オーブが 88dp で指に対して小さくないか)は E02-12 で確かめる
