# E02-09 回転オーブ

親: [E02](../epics/E02-render-ui.md)

## 概要
- 中央のドラッグで傾け、外周(半径の78%より外)のドラッグで視線まわりにひねる。回転軸はカメラの向きから決める(Web版の orb の pointermove)
- 選択中の部位の向きを、3つの輪と「前」「上」の印で描く(Web版の drawOrb)

## 進め方
ドラッグから回転への変換は `:core` でテスト先行、描画は手動確認

## 完了条件
- ドラッグ量から回転への変換をJVMテストで確かめ、エミュレータで部位と肋骨を回せる
