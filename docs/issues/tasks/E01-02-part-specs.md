# E01-02 部位の定義データと左右の鏡像化

親: [E01](../epics/E01-logic-port.md)

## 概要
20部位の寸法・取り付け位置・a0・ref・コーン・ロール・ヒンジ・親子関係を、Web版の `spec` から移す。右側は ±x のコーンを入れ替え、ロールを反転する。

## 完了条件
- 20部位と親子関係がWeb版と一致する
- 右側の鏡像化のテストが通る

## 依存
E01-01

## 設計の決定
- 部位の id は Web版の name と同じ文字列(`rib`、`upperArmL` など)。E01-10 で Web版と突き合わせやすくするため
- 定義は左側の値で書き、右側は取り付け位置・休止方向の x を反転、コーンの ±x を入れ替え、ロールを鏡像にする(Web版の makePart と同じ)。ヒンジは左右で同じ
- 角度は定義の時点でラジアンに変換して持つ
- メッシュの寸法(太さ・箱の大きさ)は描画用なので持たない。E02 で扱う
- 肋骨の初期位置(0, 1.10, 0)は骨格の状態なので E01-08 で扱う

## 検証結果
- テスト先行: `PartSpecsTest` を書き、コンパイルエラーで失敗することを確認してから実装した
- `./gradlew :core:test` → `PartSpecsTest` 15件を含め、全29件が成功
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(lint は 0 errors、既存の警告5件のみ)

## 未検証のまま残したこと
- Web版のロールの定義はすべて左右対称なので、非対称のロールの鏡像は `RollRange.mirrored()` の単体テストでだけ確かめた
