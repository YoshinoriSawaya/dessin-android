# E17-03 膝蓋骨と膝蓋腱

親: [E17](../epics/E17-knee-structure.md)

## 概要
- 膝蓋骨(小さな楕円の板)を大腿骨の丸みの前面に置き、曲げ角に応じて丸みに沿って下へ回り込ませる
- 膝蓋腱(細い線)は膝蓋骨の下端と脛骨粗面(すねの前面の上)を結び、長さは一定
- 位置は曲げ角から計算し、状態には持たない。見た目はすねの部位に含める(すねを置いたときに出る)

## 進め方
位置の計算は `:core` でテスト先行。見た目はエミュレータと実機で確かめる

## 完了条件
- 曲げても腱の長さが変わらないこと、曲げるほど膝蓋骨が下へ回ることをテストで確かめる
- 曲げたときに膝が前へ出っ張って見える

## 検証結果
- `KneeCapTest`(腱の長さが一定・曲げるほど下へ回る・丸みの中心からの距離・ひねっても正中・見た目の置き方・左右の鏡像)を先に書いた。ただし赤の確認(実行して失敗するのを見ること)は省き、実装と同時に通した
- 位置の計算は `kneeCap`(`skeleton/Knee.kt`)。膝蓋骨と膝蓋腱はすねのメッシュに含め(`PartMesh.knee`)、置き方はももの変換に載せて `meshWorldMatrix` で求める(描画・ピッキング・影・全体を表示がそのまま従う)
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(:core のテスト487件、失敗0件・止めているもの0件。lint は既存の警告5件のみ)
- エミュレータ: 左のももを前へ・すねを 109° 曲げた姿勢を横から見て、膝蓋骨が膝の前上に、腱がすねの前面に沿って出ること、伸ばした右ひざでは膝蓋骨が関節の少し上の前面に出ることを見た

## 未検証のまま残したこと

- 膝蓋骨・腱に触れると、すねが選ばれる(すねの見た目に含めたため)
