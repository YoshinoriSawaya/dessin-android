# E17-03 膝蓋骨と膝蓋腱

親: [E17](../epics/E17-knee-structure.md)

## 概要
- 膝蓋骨(小さな楕円の板)を大腿骨の丸みの前面に置き、曲げ角に応じて丸みに沿って下へ回り込ませる
- 膝蓋腱(細い線)は膝蓋骨の下端と脛骨粗面(すねの前面の上)を結び、長さは一定
- 位置は曲げ角から計算し、状態には持たない。見た目はすねの部位に含める(すねを置いたときに出る)

## 進め方
位置の計算は `:core` でテスト先行。見た目はエミュレータと実機で確かめる

## 完了条件
- 曲げても腱の長さが変わらないこと、曲げるほど膝蓋骨が下へ回ることをテストで確かめる
- 曲げたときに膝が前へ出っ張って見える
