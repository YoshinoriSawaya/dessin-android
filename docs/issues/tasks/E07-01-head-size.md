# E07-01 頭の大きさの基準を 70% にする

親: [E07](../epics/E07-body-type.md)

## 概要
- 頭の大きさの基準を、いまの 70% にする(2026-11-14、利用者)
- そこからの調整は E07-02 の体型の項目として扱う

## 確認したいこと
- 首の付け根・首の長さとの見た目の釣り合い(実機で見る)

## 進め方
`:core` の部位の定義を変えるのでテスト先行。見た目は実機で確認

## 完了条件
- 部位の定義のテストが通り、実機で見た目を確かめる

## 依存
なし

## 設計の決定
- 頭の関節の拡大率に基準 `HEAD_BASE_SCALE = 0.7` を掛ける(`jointScale`)。スライダーの 100% が新しい基準になり、60〜140% の範囲も新しい基準に対して効く
- 保存データの頭の大きさ(倍率)はそのまま新しい基準に対する倍率として読む。保存済みのポーズの頭は 0.7 倍で表示される(基準を変えるという要望どおり。保存形式の版は上げない)
- 頭の可動域の表示(緑の範囲と玉)の半径は、これまでどおり親(首)の拡大率で決まり、頭の大きさは効かない

## 検証結果
- テスト先行: `頭の大きさの基準はv1の70パーセント` を書き、`HEAD_BASE_SCALE` が無いことで失敗するのを確認してから実装した
- 既存のテスト3か所の期待値を変えた。理由: 頭の拡大率が「倍率」から「基準 0.7 × 倍率」に変わる仕様の変更のため(確かめる内容は変えていない)
  - `BodyParamsTest.頭の大きさは頭の関節の拡大率`: 1.3 → 1.3 × 0.7
  - `SkeletonTest.体型の調整が関節の位置と拡大率に効く`: 1.5 → 1.5 × 0.7
  - `SkeletonTest.肋骨の回転と拡大は子孫に効く`: 2.0 → 2.0 × 0.7
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト277件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37、`--es demo all --es select head`): 頭が小さくなり、スライダーは 100% を示す。クラッシュなし

## 未検証のまま残したこと
- 実機での見た目(首の長さ・付け根との釣り合い)。首の長さは E07-02 で調整できるようにする
- 頭の可動域の表示(緑の範囲と玉)は v1 の頭の大きさの位置に残り、小さくなった頭から少し離れて見える。操作に困るようなら半径に基準を掛ける
