# E13-01 場面のデータ(複数の人形と操作中の人形)

親: [E13](../epics/E13-multi-doll.md)

## 概要
- 複数の人形(それぞれ骨格・体型・根・手の形を持つ)と、操作中の人形を持つ「場面」のデータを作る
- 今の操作(選ぶ・向ける・スライダー・オーブ・保存)は、操作中の人形に対して働くようにする

## 決まったこと
- 体型は人形ごとに別(2026-11-14、利用者)
- 新しい人形は、今いる人形のいちばん右の隣(0.6 右)に、胸だけを置いた初めの状態で置く(Claude が決めた)

## 進め方
`:core` でテスト先行

## 完了条件
- 場面に人形を足す・外す・切り替えるテストと、操作中の人形だけが変わるテストが通る

## 依存
なし

## 設計の決定
- 操作中の人形は今までどおり `EditorState.skeleton` に持ち、ほかの人形を `others`、操作中の人形の位置を `activeDoll` に持つ。今までの操作(選ぶ・向ける・スライダー・オーブ・体型・手の形・根)はそのまま操作中の人形に効く。場面の全員は `dolls`
- `addDoll`(10体まで)・`switchDoll`・`removeDoll`(操作中の人形を消し、前の人形を操作中に。最後の1体は消せない)。切り替え先に選んでいた部位が無ければ胸を選ぶ
- 全体を表示はすべての人形を囲む箱に合わせる
- 画面の状態(`EditorStateCodec`)に `active` の行と、操作中でない人形を1体1行(`otherdoll <根>|<体型>|<ポーズ>`)で残す

## 検証結果
- テスト先行: `DollSceneTest`(初めは1体・足す・操作は操作中だけ・体型は人形ごと・切り替え・胸に戻る・範囲外・10体まで・消す・全体を表示・画面の状態・置く位置)を書き、未定義でコンパイルが通らないことを確認してから実装した。既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト378件、うち照合3件は停止、失敗0件。lint は既存の警告5件)

## 未検証のまま残したこと
