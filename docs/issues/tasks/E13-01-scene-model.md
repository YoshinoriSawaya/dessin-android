# E13-01 場面のデータ(複数の人形と操作中の人形)

親: [E13](../epics/E13-multi-doll.md)

## 概要
- 複数の人形(それぞれ骨格・体型・根・手の形を持つ)と、操作中の人形を持つ「場面」のデータを作る
- 今の操作(選ぶ・向ける・スライダー・オーブ・保存)は、操作中の人形に対して働くようにする

## 確認したいこと
- 体型を人形ごとに別にするか(E13 全体の確認事項)
- 新しい人形を置く位置(前の人形の横にずらす、など)

## 進め方
`:core` でテスト先行

## 完了条件
- 場面に人形を足す・外す・切り替えるテストと、操作中の人形だけが変わるテストが通る
