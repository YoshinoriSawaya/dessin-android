# E14-02 胸の上端を斜めに切る

親: [E14](../epics/E14-usage-feedback.md)

## 概要
- 胸の形の首側(上端)を斜めに切りたい(2026-11-14、利用者)

## 決まったこと(2026-11-15、利用者)
- 向きは両方: 前(鎖骨のくぼみの側)が低く後ろが高い、かつ中央から肩に向かって下がる

## Claude が決めたこと(利用者に伝えた。実機で見て調整する)
- 角度は前へ 25°・肩へ 15° から始める
- 首の付け根・肩の付け根・乳房の位置は今のまま(切り口の高さに近いことを確かめる)

## 関連
- E08-01(胸を肋骨の形にした)。今の胸は、上端が水平に切れた旋盤体(上端 y = 0.15、半径 0.085)

## 進め方
胸の形を `:core` でテスト先行(切り口の高さ)。見た目はエミュレータで確かめる

## 完了条件
- 胸の上端が、前と肩の側で低くなっていることをテストで確かめる
- 胸の線(前後の縦線)も切り口で止まる
- エミュレータで、首・肩の付け根との間に隙間や大きな突き抜けが無い

## 設計の決定
- 切り口の高さ `PartVisuals.chestTopY(x, z)` = 上端 0.15 −tan25°×(z − 背中側の縁の z)−tan15°×|x|。後ろの中央が最も高く、前と肩へ下がる(前の縁は約 0.123、肩の側は後ろより 2cm 以上低い)
- 胸は旋盤体をやめ、列(縦の輪郭)ごとに切り口の高さで止めた面を作り、切り口には斜めのふた(縁の重心から扇)をした。法線は輪郭の接線から前後の縮みに合わせて求める
- 前後の縦線は切り口で止める。y = 0.06 の輪・乳房・首と肩の付け根の位置は変えない(付け根は切り口から 1cm 以内)
- 胸の長さ(E14-03)は形ごと縦に伸ばすので、切り口の角度も一緒に変わる

## 検証結果
- テスト先行: `ChestShapeTest` に3件(切り口が前と肩で低い・付け根が切り口の近く・前の縦線が切り口で止まる)を書き、未定義でコンパイルが通らないことを確認してから実装した
- 実装後、自分で足したテストの準備を1つ直した: 前の縁を「x = 0・z > 0 の頂点」で選んでいたが、ふたの真ん中の頂点が混ざったので、前と横の面の頂点(z > 0.05・x > 0.05)に絞った。期待する値は変えていない
- 既存のテスト(高さ・最も広い位置・厚み・脇腹とのつながり・線の本数)はそのまま通る
- `./gradlew lint test assembleDebug` → 成功
- エミュレータ(AssetDash_API37): 横から見て前が低く後ろが高い切り口、正面から見て中央が高く肩へ下がる切り口になる。首は切り口の後ろ寄りから出る

## 未検証のまま残したこと
- 角度(前 25°・肩 15°)の良し悪しは実機で利用者が見る
- 肩(鎖骨の円柱)の端が、肩へ下がった切り口より少し上に浮いて見える。気になれば肩の付け根を切り口に合わせて下げる
- ふたは上向きの面なので明るく見える(陰影は他の面と同じ規則)
