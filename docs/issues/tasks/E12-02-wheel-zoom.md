# E12-02 マウスホイールでの拡大縮小

親: [E12](../epics/E12-camera-mode.md)

## 概要
- マウスホイールで拡大縮小できるようにする(2026-11-14、利用者。スマホではあまり使わないが、マウスをつないだときやエミュレータで便利)
- 上へ回すと近づき(ズームイン)、下へ回すと離れる(ズームアウト)。一刻みで距離を 0.9 倍
- 部位の操作とぶつからないので、カメラだけを操作するモードによらずいつでも効く

## 進め方
拡大縮小の計算(`:core`)はテスト先行。ホイールのイベントの受け取り(`:app`)は手動確認

## 完了条件
- 計算のテストが通り、エミュレータ・実機でホイールを回すと拡大縮小する

## 依存
E12-01

## 設計の決定
- `EditorState.wheelZoom(steps)`: 距離を 0.9 の steps 乗にする(上へ一刻みで 0.9 倍、下へ一刻みで 1/0.9 倍)。細かい刻み(タッチパッドなど)は割合で効く。距離の範囲(0.8〜9.0)に収める。視点の向き・注視点・ポーズは変えない
- `DollSurfaceView.onGenericMotionEvent` でポインタ(マウス)の ACTION_SCROLL の縦の量を受け取る。ヒントは最初の操作で消す(指で触ったときと同じ)

## 検証結果
- テスト先行: `WheelZoomTest`(向き・一刻みの量と戻り・ほかは変えない・モードによらない・範囲・視点が未定のとき)を書き、未定義でコンパイルが通らないことを確認してから実装した。既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト367件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37、`adb shell input mouse scroll ... --axis VSCROLL,±1`): 上へ3刻みで近づき、下へ6刻みで初めより離れる。クラッシュなし

## 未検証のまま残したこと
- 実機にマウスをつないだときの、一刻みの量の感覚(端末やマウスによって一刻みの値が違うことがある)
