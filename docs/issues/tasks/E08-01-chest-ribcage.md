# E08-01 胸を肋骨の形にする

親: [E08](../epics/E08-body-shapes.md)

## 概要
- 胸を、肋骨のように上と下が狭まった形にする(2026-11-14、利用者)
- 変えるのは胸のメッシュ。E05 で分けた脇腹との継ぎ目が不自然にならないようにする

## 進め方
形状の生成(`:core`)はテスト先行。見た目は実機で確認

## 完了条件
- 形状のテストが通り、実機で見た目を確かめる

## 依存
なし

## 設計の決定
- 胸を、輪郭を y 軸まわりに回した形(旋盤体、`Primitives.lathe`)にし、前後を 0.64 倍に縮めた(厚みの比は今と同じ)
- 輪郭(胸の関節の空間): 下端 y = −0.045 で半径 0.106、y = 0.03 で最も広く 0.12、上端 y = 0.15 で 0.085。上下それぞれ放物線でなめらかにつなぐ(`PartVisuals.chestRadius`)
- 脇腹の上端の半径を胸の下端(0.106)に合わせた(継ぎ目に段差が出ない)
- 前後の縦線は輪郭に沿わせ、輪は今と同じ高さ(y = 0.06)に置いた

## 検証結果
- テスト先行: `ChestShapeTest`(高さ・中ほどが最も広く上下が狭い・厚みの比・脇腹とのつながり・線)を書き、「最も広いのが中ほど」が失敗するのを確認してから実装した。既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト309件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37): 正面で胸の上が狭まり中ほどが広い形になり、脇腹と段差なくつながる。横から見ても破綻なし。クラッシュなし

## 未検証のまま残したこと
- 実機での見た目(狭まり方の強さ)。数値は `chestRadius` の3つの値で調整できる
