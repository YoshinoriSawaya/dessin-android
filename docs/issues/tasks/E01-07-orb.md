# E01-07 回転オーブ(スイング・ツイスト分解)

親: [E01](../epics/E01-logic-port.md)

## 概要
`sphereRotate`: 回転をスイングとツイストに分解し、roll を [−π,π) に折り返したうえで、可動域とロール範囲にクランプする。肋骨は回転をそのまま掛ける。

## 完了条件
- 純粋なツイストやスイングの分解、範囲外の roll のクランプのテストが通る

## 依存
E01-04

## 設計の決定
- `orbRotate(spec, current, rotInParent)` は親の空間での回転を受け取り、新しい状態を返す純粋関数にした。ワールドの回転から親の空間への変換(pq⁻¹·dw·pq)は E01-08 で行う
- スイングを可動域に収める部分は、Web版では sphereRotate の中に aimPart と同じ式が書かれている。ここでは、スイング後の向きを親の空間に戻して `aimPart` を呼ぶ形で共通にした
- 肋骨(根)用に `orbRotateRoot`(ワールドの回転を後から掛ける)を置いた

## 検証結果
- テスト先行: `OrbTest` を書き、コンパイルエラーで失敗することを確認してから実装した
- `./gradlew :core:test` → `OrbTest` 9件を含め、全77件が成功
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(lint は 0 errors、既存の警告5件のみ)

## 未検証のまま残したこと
- Web版のロールの範囲はすべて対称なので、非対称なロールの範囲での収め方は確かめていない
- オーブの操作感(中央と外周のドラッグ)は E02 で確かめる
