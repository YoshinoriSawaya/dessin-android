# E04-02 足の付け根を直接選べるようにする

親: [E04](../epics/E04-device-feedback.md)

## 概要
- 実機確認で判明: 付け根の円柱は骨盤の中に埋まっていて、タップしても骨盤に当たる(部位チップからしか選べない)
- B: 付け根を、骨盤の側面から少しはみ出す短く太い円柱(半径 0.045、骨盤の外面から 0.02 外まで)にして見えるようにする
- A: タップが骨盤に当たり、その点が脚の付け根の関節から 0.09(骨盤の拡大率を掛ける。当初案の 0.06 では骨盤の前面が関節より約 0.06 手前にあって届かなかった)以内なら、近いほうの側の付け根を選ぶ(置いていなければ置く)

## 完了条件
- ピッキングの規則をテスト先行で確かめ、実機で骨盤の左右の下側をタップして付け根を選べる

## 依存
E04-01

## 検証結果
- テスト先行: `HipPickTest`(4件)・`HipVisualTest`(2件)を書き、失敗することを確認してから実装した
- 途中で直したテスト: 真横から付け根を狙うテストは、全部位を置くと垂らした左の前腕がレイの手前に来ていた(テストの前提の誤り)ので、脚の側だけ置いた状態で確かめる形にした。「付け根に輪郭が無い」の旧テストは、輪郭を付けた仕様の変更なので期待値を書き換えた
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト261件、うち照合3件は停止、失敗0件。lint は既存の警告5件のみ)
- エミュレータ(AssetDash_API37)で確認: 骨盤の左右から付け根の円柱がはみ出して見え、タップすると「左付け根」が選ばれて玉と可動域が出る

## 未検証のまま残したこと
- 実機での確認(作業中に実機の接続が切れたため。E04-03 の首の位置と一緒に見てもらう)
- 骨盤を選んでいて、脚の付け根の近くを押して骨盤をドラッグしたいときは、付け根が選ばれるようになった(骨盤は中央か玉を押せば動かせる)
