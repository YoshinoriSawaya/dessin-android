# E07-03 体型の保存

親: [E07](../epics/E07-body-type.md)

## 概要
- 体型に名前を付けて保存・読み込みできるようにする。ポーズとは別に保存する(2026-11-14、利用者)
- E03(ポーズの保存)の仕組みを参考にする。読み込みの失敗は結果型で返す

## 決まったこと(2026-11-14、利用者)
- ポーズからは体型を外す。ポーズは姿勢(と胸の置き方・大きさ)だけを持ち、読み込んでもいまの体型のまま
- 体型の文字列は E07-02 の `BodyCodec` を使う

- 保存済みのポーズ(版2までの体型を含むもの)を読み込んだとき、体型の部分は読み飛ばす
- 頭を外しても頭の大きさは戻さない(体型は部位を外しても変わらない)
- 「体型」の行を足し、「名前を付けて保存」「保存した体型」を置く

## 進め方
保存形式は `:core` でテスト先行。画面は手動確認

## 完了条件
- 保存形式のテストが通る(壊れたデータは結果型で失敗を返す)
- 実機で保存・読み込みできる(日本語の名前を含む)

## 依存
E07-02

## 設計の決定
- ポーズの保存形式を版3にし、体型の行を外した。版1・2の体型の行は読めるように残した(v1 の画面の状態を引き継ぐため)。保存したポーズを読み込むとき(`loadPose`)は、いまの体型を保つ
- 保存の一覧をポーズと体型で共通の `NamedLibrary` にした(`PoseLibrary`・`BodyLibrary`)。1件のファイルの4行目が `pose` か `body` で、違うものは読めないファイルとして扱う。名前の候補は「体型 N」
- 体型のファイルは files/bodies に `<id>.body` で置く(ポーズは files/poses の `<id>.pose`)
- 体型を読み込む(`loadBody`)と体型だけを差し替え、ポーズ・選択・視点は保つ
- 部位を外しても体型を変えない(v1 は頭を外すと頭の大きさを戻していた)
- 画面: 操作パネルに「体型」の行を足した。ダイアログは種類で題名と文言を切り替える

## 検証結果
- テスト先行: `BodyLibraryTest`、`PoseCodecTest`(版3は体型を書かない・版2の体型は読める)、`LoadPoseTest`(読み込んでも体型を保つ)、`LoadBodyTest` を書き、未定義でコンパイルが通らないことを確認してから実装した
- 既存のテストを変えた。理由: ポーズから体型を外す・頭を外しても戻さない仕様の変更のため
  - `PoseCodecTest` の骨格の材料から体型を外した。体型の行のエラーと範囲のテストは版2のデータで書き直した
  - `SkeletonTest.頭を外すと頭の大きさが戻る_肩幅は戻らない` → `部位を外しても体型は変わらない`
  - `ChestFlankTest.新しい保存データは版2` → `版2以降`(版3に上げたため。脇腹を保存して戻せることは同じ)
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(テスト304件、うち照合3件は停止、失敗0件。lint は既存の警告5件)
- エミュレータ(AssetDash_API37): 腕の長さを 128% にして「体型 1」で保存 → 75% に縮める → v1 で保存した版2のポーズ「ポーズ 1」を読み込むと腕は 75% のまま → 「体型 1」を読み込むと 128% に戻り、ポーズと選択中の部位は保たれる。ファイルは files/poses と files/bodies に分かれる。クラッシュなし

## 未検証のまま残したこと
- 実機での操作感
- 「体型」の行を足したので操作パネルが一段高くなり、3D の画面がそのぶん低くなった(縦が短い端末で窮屈でないか)
- 体型の一覧の削除は画面で試していない(ポーズと同じ仕組み)
