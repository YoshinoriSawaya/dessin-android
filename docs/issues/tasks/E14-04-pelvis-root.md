# E14-04 骨盤が根のとき、骨盤で全体を動かす・回す

親: [E14](../epics/E14-usage-feedback.md)

## 概要
- 胸を根にしているときは、胸を回転オーブで回すと全体が回る(正しい)
- 骨盤を根にしているときは、骨盤を回転オーブで回すと骨盤の角度だけが変わる(間違い)。胸と同様に全体が回るべき(2026-11-14、利用者)

## 決まったこと(2026-11-15、利用者)
- 骨盤が根のときは、骨盤の操作を胸と同じにする
  - 回転オーブで全体を回す。回す中心は骨盤の関節
  - ドラッグで全体の位置を動かす
  - 胸と同じ「前後の傾き・ひねり・横の傾き」のスライダーを出し、全体が回る
- 骨盤が根のときの脇腹のひねりの向き(E10-01 の未検証事項)も見直す

## 関連
- E10-01(根の切り替え)。データはいつも胸を根に持ち、骨盤が根のときは胸の置き方を補正して骨盤を止めている。全体を回すには、骨盤の関節を中心に胸の置き方を回す形になる見込み

## 進め方
`:core` でテスト先行(骨盤の関節が動かない・全体が回る・位置が動く)。操作感は実機で利用者が確かめる

## 完了条件
- 骨盤が根のとき、オーブ・スライダーで骨盤の関節のワールドの位置を保ったまま全体が回ることをテストで確かめる
- ドラッグで全体が動く
- 胸が根のときの操作は今までどおり(既存のテストが通る)

## 設計の決定
- 骨格に `isAnchorRoot(id)`(骨盤が根で骨盤を置いていて、id が骨盤)を足した。データは今までどおり胸を根に持ち、全体の操作は胸の置き方を変えて行う
  - `rotatedAbout(中心, 回転)`: 胸の置き方を、ワールドの点を中心に回す。部位の状態(体の形)は変えない
  - `movedBy(ずれ)`: 胸の位置をずらす
- 回転オーブ(`Skeleton.orb`): 骨盤が根のときの骨盤は、骨盤の関節を中心に全体を回す
- スライダー: 骨盤が根のときの骨盤は、胸と同じ「前後の傾き・ひねり・横の傾き」を、骨盤のワールドの向きをオイラー角(YXZ)に分けた値で出す。動かすと骨盤のワールドの向きの1軸を差し替え、その差の回転で骨盤の関節を中心に全体を回す。骨盤自身の「ひねり」の行は出さない(全体のひねりと名前が重なり、骨盤と脇腹の間のひねりは脇腹で付けられるため)。骨盤の横幅・付け根の内寄りは今までどおり。胸の大きさ・身長・乳房は胸だけ
- ドラッグ(`TouchGesture`): 骨盤が根のときの骨盤は、胸と同じく全体を動かす。指の動きを骨盤の関節の奥行きで換算する
- 向きを戻す: 骨盤が根のときの骨盤は、位置を保って骨盤のワールドの向きを初めの向き(まっすぐ)に戻す。胸の「向きを戻す」は位置も戻すが、骨盤では位置を保つことにした(全体の配置を崩さないため)
- 骨盤が根のときの骨盤には緑の範囲・玉を出さない(`drawPlan`。胸と同じ)。説明の文も胸と同じ「ドラッグで画面上の位置を決めます。」
- 脇腹のひねり: 骨盤が根のとき、スライダーの値の符号を逆にして見せ・反映する。こうすると、+ にしたとき動く側(上半身)が、胸が根のときの動く側(骨盤)と同じ向きに回る。E10-01 で決めた「骨盤が根のときの脇腹の操作は上半身を動かす向き」(玉・回転オーブ)にそろえた。データ(脇腹の状態)の意味は変えないので、保存した場面はどちらの根でも同じ形になる

## 検証結果
- テスト先行: `PelvisRootTest`(9件。回転オーブ・傾きのスライダーの値と反映・ひねりの行を出さない・ドラッグ・緑の範囲を出さない・向きを戻す・説明の文・脇腹のひねりの向き、と胸が根のときは今までどおり)を書き、8件が失敗することを確認してから実装した(通った1件は胸が根のときの回転オーブで、今までの動きを確かめるもの)
- 実装後に新しいテストの準備の誤り2件を直した(実装ではなくテストの側)
  - ドラッグ: 押す点を骨盤の形の前面の真ん中にしていたが、メッシュの縦の継ぎ目に当たって部位を拾わなかった。少し横の点にした
  - 脇腹のひねり: 回る量が一致することまで求めていたが、脇腹を 15° 曲げた姿勢では胸と骨盤の上から見た回り具合が少し違う。向き(符号)が同じことを確かめる形にした
- 既存のテストは変えていない
- `./gradlew lint test assembleDebug` → BUILD SUCCESSFUL(:core のテスト411件、うち照合3件は停止、失敗0件。lint は既存の警告5件のみ)
- エミュレータ(AssetDash_API37、`--es demo natural --es select flank`): 根を骨盤にして骨盤を選ぶと、説明が「ドラッグで画面上の位置を決めます。」、スライダーが前後の傾き・ひねり・横の傾き・骨盤の横幅・付け根の内寄りになり、緑の範囲は出ない。横から見て前後の傾きを 60° にすると、骨盤を中心に人形全体が前へ倒れる。「向きを戻す」でまっすぐに戻る。骨盤を押して右へドラッグすると、姿勢を保ったまま全体が右へ動く(視点は動かない)。回転オーブでも骨盤を中心に全体が回り、スライダーの値が追従する。クラッシュなし

## 未検証のまま残したこと
- 実機での操作感
- 横から見ると腕が骨盤に重なり、骨盤を押したつもりで腕を押して視点が回ることがある(骨盤を押しにくい)。部位チップで選んでからスライダー・オーブで操作はできる
- 骨盤が根で骨盤を外したとき(根は自動的に胸の扱いになる)の画面の表示は試していない
- 骨盤のオイラー角は、横の傾きが ±90° に近いと値が飛ぶことがある(胸と同じ)
