# E14-04 骨盤が根のとき、骨盤で全体を動かす・回す

親: [E14](../epics/E14-usage-feedback.md)

## 概要
- 胸を根にしているときは、胸を回転オーブで回すと全体が回る(正しい)
- 骨盤を根にしているときは、骨盤を回転オーブで回すと骨盤の角度だけが変わる(間違い)。胸と同様に全体が回るべき(2026-11-14、利用者)

## 決まったこと(2026-11-15、利用者)
- 骨盤が根のときは、骨盤の操作を胸と同じにする
  - 回転オーブで全体を回す。回す中心は骨盤の関節
  - ドラッグで全体の位置を動かす
  - 胸と同じ「前後の傾き・ひねり・横の傾き」のスライダーを出し、全体が回る
- 骨盤が根のときの脇腹のひねりの向き(E10-01 の未検証事項)も見直す

## 関連
- E10-01(根の切り替え)。データはいつも胸を根に持ち、骨盤が根のときは胸の置き方を補正して骨盤を止めている。全体を回すには、骨盤の関節を中心に胸の置き方を回す形になる見込み

## 進め方
`:core` でテスト先行(骨盤の関節が動かない・全体が回る・位置が動く)。操作感は実機で利用者が確かめる

## 完了条件
- 骨盤が根のとき、オーブ・スライダーで骨盤の関節のワールドの位置を保ったまま全体が回ることをテストで確かめる
- ドラッグで全体が動く
- 胸が根のときの操作は今までどおり(既存のテストが通る)
