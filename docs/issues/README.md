## 実機で見てほしいところ
v1.1.0(E07〜E11):
- 体の形: 胸の狭まり方、指の開き方と親指、つま先(玉に隠れて曲がり具合が見えにくい)、乳房と性器の形と大きさ
- 自然な姿勢の角度(首 15°・脇腹 10°・付け根 20°・もも 5°)
- 根を骨盤にしたときの脇腹の操作感
- 影: 操作中の重さ、濃さとぼけ具合
- 操作パネルが高くなった(胸のスライダー6本・「体型」の行)ことで、3D の画面が狭くないか
- 頭の可動域の表示が小さくなった頭から浮いて見える、首を長くすると首の可動域の表示が大きく広がる

v1.2.0(E12・E13):
- カメラのモード: 2本指の平行移動(エミュレータでは試せていない)、ボタンの位置
- マウスホイールの一刻みの量
- 複数の人形: 10体のときの重さ、操作中の人形の見分けやすさ(今は選択中の部位の色だけ)、人形のモードの使い勝手、場面の保存と読み込み

## 決まっていないこと(利用者に確認する)
- 脇腹の可動域: 前 25°・後ろ 20°・左右 20°・ひねり ±30° は Claude の案のまま。実機で触って調整する
- Claude が仮に決めた既定: 乳房 0%・性別 男、影はオン
- 脇腹の「前傾」の向き: 上の端(胸)が前に出る向きと解釈した(骨盤は胸より少し後ろ)。逆なら直す
