# E17 膝の構造(転がり・回旋・膝蓋骨)

## 概要
膝を単純な蝶番ではなく、大腿骨の円柱が脛骨の台の上を転がる簡略モデルにする。もとは利用者の整理メモ「膝の構造整理(デッサン人形用)」(2026-11-19)。

メモの要点:
- 状態は屈曲角 θ と回旋角 φ の2つ。膝蓋骨の位置と転がり量は θ から計算し、状態には持たない
- 回旋は曲げたときだけ。伸展時はほぼ 0°、屈曲 90° で外旋約 40°・内旋約 30°。屈曲角が大きいほど広がる
- 膝蓋腱は長さ一定。曲げると膝蓋骨が大腿骨の円柱の前面から下へ回り込む
- 内反・外反(左右のぶれ)と過伸展は無し

## 決まったこと(2026-11-19、利用者)
- 反映先は Kotlin 版(Web版は今後使わない。CLAUDE.md)
- 屈曲の上限は 150° のまま(メモの目安 135° より深くしゃがめるようにする。保存済みのポーズとも合う)
- 回旋 φ は既存のひねりスライダーで操作する(3D 上のノブは作らない)
- 範囲: 屈曲で変わる回旋の可動域、回転中心を θ で動かす(転がり)、膝蓋骨と膝蓋腱の表示、扇形の可動域表示の4つすべて
- 大腿骨の軸のずれ(円柱の中心の高さ)は、既存の「ひざの転がり」(kneeRoll、既定 0.03)をそのまま使う
