# E18 手に持たせる棒

## 概要
手に棒を持たせられるようにする。要望は 2026-11-19 の利用者:「多少角度をいじれて、長さを調節できる、細長くて、縦横のわかる板状の直方体」。

## 決まったこと(2026-11-19、利用者)
- 棒は手の子の部位にする(左右の「棒」)。ほかの部位と同じく、緑の範囲の玉・回転オーブ・ひねりのスライダーで向きを変え、外す・左右のコピー・Undo・保存もそのまま効く
- 向きの基準は、拳を握ったときに指の中を通る向き(手の平に沿って前後)。そこから ±45°、ひねり ±90°
- 長さと握る位置(棒のどこを握るか。端〜真ん中〜反対の端)をスライダーで変える
- 棒を置いたら、手を自動でグーにする(あとでパーにも戻せる)
