# E19 プリセットのポーズ

## 概要
決まった姿勢をすぐ当てられるようにする。要望は 2026-11-19 の利用者(「次のフェーズの候補」にあったもの)。

## 決まったこと(2026-11-19、利用者)
- ポーズは9つ: 立つ・歩く・走る・座る(椅子)・しゃがむ・体育座り・あぐら・手を挙げる・腕を広げる。椅子は無いので、座る姿勢は宙に浮く
- 当てると、操作中の人形のポーズだけを差し替える(全部位を置いてその姿勢にする)。体型・位置・床の上での向き・大きさ・棒は保つ。Undo で戻せる
- 入り口は「保存」の行の「プリセット」。押すと一覧のダイアログが出て、選ぶと当てる
