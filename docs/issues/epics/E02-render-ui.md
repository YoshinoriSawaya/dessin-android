# E02 3D描画とUI

## 概要
E01 のロジックを使い、Web版と同じ操作を Android で行えるようにする。描画は GLSurfaceView + OpenGL ES 3.0、UI は Compose。縦向き固定。

## 範囲
- 部位の描画(円柱・箱・球・正中線の管)、可動域(半透明の緑)、玉、影・床・格子
- 部位の選択(チップ・3D上のタップ)、外す、向きを戻す
- 玉のドラッグ、緑領域のダブルタップ(420ms以内・32px以内)
- 回転オーブ
- スライダー(肋骨の大きさ・傾き・ひねり、各部位のひねり、頭の大きさ、肩幅、骨盤の横幅、付け根の内寄り)
- 肋骨のドラッグ移動
- カメラ: 1本指での回転、ピンチでのズーム、正面・横・背面・上、全体を表示
- 表示の切替: ガイド、正中線、関節の玉、格子
