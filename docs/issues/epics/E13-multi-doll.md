# E13 複数の人形

## 概要
複数の人形を同時に画面に置けるようにする。要望は 2026-11-14 の利用者の指摘。
いまは骨格・選択・保存がすべて人形1体を前提にしているので、データの持ち方から変わる大きな変更になる。
