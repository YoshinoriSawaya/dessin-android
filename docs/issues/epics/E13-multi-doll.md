# E13 複数の人形

## 概要
複数の人形を同時に画面に置けるようにする。要望は 2026-11-14 の利用者の指摘。
いまは骨格・選択・保存がすべて人形1体を前提にしているので、データの持ち方から変わる大きな変更になる。

## 決まったこと(2026-11-14、利用者)
- 10体まで置ける
- 体型は人形ごとに別
- 人形の操作: 「カメラ」のボタンの下に「人形」のボタンを置き、押すとパネルが人形のモード(人形の選択・追加・削除)になる
- 保存は場面としてまとめて(全員の位置・ポーズ・体型)。今までの1体のポーズは、読み込むと操作中の人形に入る

## Claude が決めたこと(利用者に伝えた)
- 人形のモード中は、3D で人形をタップするとその人形に切り替わる。人形のモードでないときは、操作中の人形だけを触れる(ほかの人形を誤って動かさないため)
- 人形どうしの位置は、今までどおり胸のドラッグで動かす

## 完了条件
実機で、複数の人形を置き、切り替えてそれぞれのポーズを組め、場面として保存・読み込みできる。
